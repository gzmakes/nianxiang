# 念响：macOS 本机启动

1. 双击同目录的 `启动念响.command`。首次启动需要 Python 3.10 或更新版本；脚本会在副本内创建 `.venv`，缺少依赖时联网安装 `requirements.txt`。
2. 保持终端窗口打开。服务准备好后，脚本会打开 <http://127.0.0.1:18787/>；若浏览器没有自动打开，请手动访问这个地址。
3. 在页面的「更多」→「数据与模型设置」中配置模型服务地址、模型名和自己的 API Key，保存后使用「测试连接」验证；无需在启动脚本里写密钥。未配置或连接失败时，对话可能使用规则引擎，不能当作模型已接通。
4. 不填也能用：没有本机配置时，念响默认走「公共演示节点」——一个云端代理函数（源码见 `nx-proxy/`），真密钥只在服务端，客户端拿不到。所以 clone 下来打开网页就能真模型对话，不用自带 Key。想强制走离线规则引擎，启动前设 `XINJI_MODEL_PUBLIC=0`。公共节点由维护者付费且有速率限制，只适合试用，不要发私密内容。
5. 结束时回到终端按 `Control + C`；下次可再次双击启动。脚本默认只绑定 `127.0.0.1`，因此手机或其他电脑无法通过局域网访问。

模型配置是此原型的本地演示实现：界面保存的 API Key 会以明文保存在副本的 `server/model-settings.json`，并尽力设置为仅当前用户可读；这不是生产级密钥管理。使用云端模型时，输入及所选上下文会发送给相应服务商。请勿将配置文件、密钥或真实敏感数据打包分享；先使用测试数据。界面测试连接成功只表示该次调用成功，不能代表长期可靠。

如果终端提示端口 18787 被占用，请先关闭占用该端口的程序再重试；同一目录下已经运行的念响会直接打开现有预览；不会关闭已有进程。其他服务占用端口时会停止启动并说明原因。若提示缺少 Python 或依赖安装失败，请安装 Python 3.10+ 并检查网络。

这份说明仅涉及本机 Web 启动；手机真机访问、Rokid 和脑机设备连接需要各自单独验证。

## Windows 本地语音

在 PowerShell 中进入源码目录后执行：

```powershell
.\scripts\setup_windows_voice.ps1
```

这会从 `server/voice-settings.example.json` 创建被 Git 忽略的 `server/voice-settings.json`，自动使用 PATH 中的 FFmpeg。若 FFmpeg 不在 PATH，可追加 `-FfmpegPath 'C:\\Tools\\ffmpeg\\bin\\ffmpeg.exe'`。小鲸鱼音色需要另行传入 `-EnableTts -ReferenceAudio 'C:\\path\\to\\reference.wav'`，并运行 `http://127.0.0.1:9880` 的 GPT-SoVITS；没有它时 ASR、文字聊天和浏览器朗读仍可用。

语音输入使用浏览器已有的 `SpeechRecognition` / `webkitSpeechRecognition`，不会上传录音，也不需要腾讯云凭证。Chrome/Edge 支持时点击“语音”即可把识别结果放回草稿；不支持的浏览器请直接输入文字。小鲸鱼 TTS 需要本机运行 GPT-SoVITS `http://127.0.0.1:9880`。用 `./scripts/check_windows_voice.ps1` 检查本机状态。

当前产品只有一条持续对话；刷新和接入资料沿用原记录，没有欢迎弹窗或重新开始入口。旧数据库迁移保留历史，不自动合并。近60分钟40轮额度会自动恢复，无需新建对话。
