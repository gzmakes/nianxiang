# 回响 · 多端设计与验收记录

本轮依据项目根目录 `design.md`（v0.1，2026-10-29）实施。本文记录当前实现与验证范围；设计示例不作为真实用户数据、提醒数量或设备状态。

## 当前结论

Web 与 H5 已同步设计和交互，保留一条连续对话、真实来源接入及动作确认流程。最近一次前端回归为 **326/326 通过**；新增设计专项 **15 项通过**。主任务已实屏确认 Web 笔记本首屏四个来源入口完整可见。

iOS、Android 是独立原生工程，H5 只是手机浏览器入口。当前原生验证仍停留在契约、静态检查及局部测试阶段，不能据此认定已完成原生应用构建或真机验收。

## Web / H5 已实现

### 设计与布局

- 使用雾蓝、淡杏及墨色文字与主按钮；内容以白卡承载，玻璃限于导航、话题控件、输入与操作层。
- 用状态光替代嫩芽角色，状态同时有文字说明；输入、生成回复与安静状态来自实际交互，不从脑电或用户表达推断情绪。
- Web 宽屏采用 72px 导航、最大 700px 聊天内容和 392px 可收侧面板；900–1199px 使用侧面板抽屉；小于 900px 使用手机布局。
- 桌面壳的布局与命令适配另见桌面 README，不以浏览器验收替代桌面系统功能验收。
- H5 底部导航为「回响 / 对话 / 记忆」；任务、连接、角色和显示设置有实际入口。
- 对话正文为 16px，中文说明不低于 12px；触控目标按 Web/iOS 44px、Android 48px 设置。最终大字与读屏效果仍需真机验证。

### 偏好、搜索与话题

- 「减少动态」「降低透明度」「光的强度」使用共享实现，存于本设备 `xinji_ui_settings_v1`；同一浏览器来源下可通过 storage 事件同步。
- 系统的减少动态、降低透明度优先，应用关闭开关不会覆盖系统开启状态；无背景模糊能力时有实色回退。
- `⌘/Ctrl+K` 与搜索按钮查询当前已加载的消息和未删除记忆，结果可定位；搜索词不上传，不创建新对话。
- 默认提供「全部 / 日常」，未标记消息归入日常。用户可手动给已发送消息标记话题；分类只存本设备 `xinji_topic_views_v1`，不是个人记忆，不发送给模型，不另建对话。
- 没有预置「周五方案」等假话题或消息；没有编造主动提醒、简报或抑制提醒数量。

### 一个对话与真实操作

- 正常启动通过 `GET /api/conversation` 获取服务端持久的同一对话。客户端缓存、旧 fresh/demo 参数不会在正常启动时分叉出新对话。
- 无欢迎弹窗、历史对话切换、重新开始或默认整段对话删除入口；旧数据和 API 没有因此被删除。
- 来源目录使用 `GET /api/onboarding/sources` 的实际可用状态。选择来源后再展示范围和确认，通过现有真实读取、预览、接入或本地文件确认路径处理；正常入口不使用旧演示 catalog/read/start 数据。
- 飞书等来源缺授权时明确提示，只有用户继续操作才发起授权。**本轮设计验收不等于新账号授权成功，也不等于读取了真实新资料。**
- Rokid 明确标为待联调；脑电只说明实时专注度设备估计值，不声称能够解码情绪。
- 任务支持手动建立本机消息草稿、提醒记录与日历安排。默认本机保存，消息不自动发送；系统写入需单独明确选择。
- 待确认动作继续使用原动作 ID；结果未知时只核对本机记录，不自动重试系统写入。取消发生在本机预览创建期间时，不继续提交晚到结果；提交已发出后关闭窗口不冒充取消成功。
- 读取与动作预览说明处理范围、步骤与限制；没有承诺对已发送的外部操作进行无限制撤回。
- 可达的记忆新增、移动端编辑、忘记和收回资料等确认使用 HTML 弹窗，兼容 Electron 不支持原生 `window.prompt` 的情况，并保留来源与授权焦点控制。

## 仍待验收 / 未实现

1. **提醒调度与主动通知未实现完整闭环。** 本机提醒记录及系统写入入口，不等于后台定时调度或可靠的主动通知；没有对应真实统计。
2. **暗色模式尚未设计。** 当前落实浅色规范，不以系统自动换色替代暗色设计验收。
3. **硬件未完成真机联调。** Rokid 型号、官方接口、显示与撤回行为仍待验证；脑电设备在队友处，实际连接、噪声、质量不足时的处理需联合验收。
4. **真实手机的字体与读屏。** 需分别检查 iOS 大字至少 +2 档、Android 字体缩放 200%、320px 窄屏、VoiceOver/TalkBack、焦点顺序、软键盘与安全区。CSS 与行为测试不替代这些验收。
5. **低端设备性能。** 需实测 Android 低端机的玻璃、渐变、状态光、滚动和输入延迟，并验证降低透明度 / 减少动态回退效果。
6. **原生构建与设备权限。** iOS 需可用 Xcode 与模拟器/真机；Android 需 SDK、构建产物与模拟器/真机。新账号授权、系统日历/提醒真实写入应独立验收，不能从 UI 或静态检查推定成功。
