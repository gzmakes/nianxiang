## 当前剩余问题

### P1 · 交付门槛，不当作源码缺陷

1. **手机工程还不是已经运行验收的 App。** `native/ios/README.md:13`、`native/ios/ACCEPTANCE-ROUND8.md`、`native/android/VERIFICATION.md:13` 明确缺 iOS SDK / Android SDK / Compose / 模拟器 / 真机验收。用户本轮明确暂不安装 SDK，应交源码和构建入口，不能承诺已有 IPA / APK。首轮真机要覆盖来源确认、搜索定位、记忆 CAS 冲突、断网 / 杀进程恢复、键盘安全区 / 大字 / 读屏。
2. **脱离这台 Mac 的可达性与身份仍未实现。** `server/api_contract.py:278` / `279` 声明 remote_user_authentication 和 realtime_multi_device_sync 为 false；iOS APIClient.swift:24 的 HTTP 仅接受 loopback。iPhone 的 127.0.0.1 是手机自身。没有设备配对 / 用户隔离 / HTTPS 时，不可把现有本机个人服务直接开放公网当作多端接通。
3. **Windows 需要实际机器验收。** `desktop/README.md:19` 明确 Mac 上组装，不代表 exe 已启动；Python 生命周期、中文目录、文件选择、托盘、退出 / 复用后端须在 Windows 验证。
4. **合并后的新功能必须重新记录真实证据。** 本轮 iOS 40/23 为最新合成 / 宿主检查；旧 CAS / 一次跟进 URLSession 日志不包含新的周期、分段和定向停止。最终 release 统计、契约导出和包 SHA 要以最终候选重新生成。

### P2 · 具体体验 / 架构差距

1. **Android 记忆提议不可由用户选择。** `native/android/app/src/main/java/cn/xinji/echo/EchoViewModel.kt:240` 仍硬编码 `memory_proposals=false`，而 iOS `App/EchoStore.swift:13` 与 Web 允许用户选择并把当次值写入 pending。应加同义开关与原 pending 快照；默认仍关闭。
2. **Android 普通原话的失败路径更生硬。** `EchoViewModel.kt:294` 直接调用提议白名单接口；`MainActivity.kt:392` 只有该入口。普通原话 409 时应像 iOS `RootViews.swift:174` 的候选回退，保留文字、解释尚未记下、由用户再次确认新增候选。不要放宽后端白名单来掩盖此差距。
3. **周期关心没有原生管理能力。** iOS `ActionViews.swift:122` 与 `Models.swift:159` 明确 daily / 未来类型只读；Android `FollowupRules.kt:22` / `EchoViewModel.kt:202` 同样限制。当前解释真实，但创建 / 规则 / 暂停与恢复在原生仍缺，不能称五端功能齐平。
4. **原生连发等待体验仍与 Web 不同。** iOS `EchoStore.swift:154` 和 Android `EchoViewModel.kt:214` 在 pending 时阻止继续发送；Web / H5 有 850ms 合并和补充时取消旧回复。PRD `work/xinji-echo-bb3a6ef/docs/PRD-0.4.md:546` 明确“连发不抢答”。先定义统一回合政策，再补原生，不以拆成很多气泡替代回合策略。
5. **跨窗口 / 跨设备消息顺序还没有会话级协调。** `server/chat_turns.py:121` 的锁 key 包含 request_id；`main.py:925` 对不同 ID 可分别调用生成。当前同 ID 恢复已保护，但不能据此声称两个客户端同时发送有统一排序 / 取消策略。本轮 Web localStorage 账本也不是跨 tab 原子锁。升级多设备前需明确 conversation revision / cursor 和会话级排队或冲突规则。
6. **从自然对话到获准行动仍有一次界面转场。** `server/prompts.py:16` 明确模型无可执行工具，不能自行承诺提醒或记住；跟进 / 来源 / 动作表单是真实入口。PRD `:95` 的价值闭环仍可通过“预填一张可编辑、可批准的行动卡”减轻切页；必须保留独立确认和实际回执，不能用模型文字当工具完成。
7. **共享资源覆盖与发布元数据还需收口。** `desktop/panel.js:12` 等仍有独立文案；`shared/release.json:5` / `:7` 读取时仍是 67 路径、73 操作、0 success schema 与旧测试计数。root 已更新架构说明和行为规则，最终包应再同步 release；不能把所有 copy / 交互称为“一处改完自动全端更新”。
