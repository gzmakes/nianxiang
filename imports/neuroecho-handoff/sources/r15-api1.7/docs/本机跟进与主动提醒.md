# 本机跟进与主动提醒

用户在 Today 页的跟进卡片主动填写内容、时间并确认保存，可选择一次或每天，并可选安静时段。时间按创建时所选浏览器时区计算；跨越夏令时时保持当地时钟时间，跳过不存在的当地时间至当天实际存在的时间。更换时区后原跟进仍按创建时的时区计算。

页面打开并处于前台时，回响最多每 30 秒检查到期事项，并在当前页面显示提示。点击“知道了”只收起这次页面提示；实际跟进仍可在 Today 卡片中完成、暂停、恢复或取消。暂停和安静时段不会弹出提示，但 Today 内仍可看到该事项。每日跟进按“完成”记录本次完成时间并安排下次；关闭期间错过的多次不会逐条补发，重新打开后仅显示待处理的那一条。

这是本地应用内提示：不发送系统通知、邮件或第三方消息；页面/服务关闭期间不会运行或通知，也不宣称跨设备同步。保存确认、取消、暂停和完成的结果以服务器回执为准；每日完成请求携带对应次数，重复请求不会安排两次。旧的一次性跟进通过 SQLite 增量迁移保留。

验收：运行 `pytest -q tests/test_followups_store.py tests/test_followups_api.py tests/test_recurring_followups.py` 与 `node --test tests/test_followups_ui.js tests/test_followup_reminder.js`。页面展示还需要在实际浏览器检查。
