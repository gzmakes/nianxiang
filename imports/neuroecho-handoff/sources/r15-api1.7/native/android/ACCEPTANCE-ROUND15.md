# Android R15：看得见反馈，离线也能取回本机文字

本轮只在 Android 工作副本修两条用户路径。未修改共享合同、后端、凭据格式或冻结 R14，也没有最终打包。

## 弹层内的反馈

设置、记忆、跟进、来源预览、任务等标准 Sheet 共用 `EchoFeedbackPanel`；心情自定义 Dialog 及其取消/删除/放弃确认框同样接入。标题和反馈固定在弹层顶部，正文独立滚动；长反馈自己限高可滚，避免保存按钮位于底部时错误仍藏在滚动区域外。

反馈读取实际 `notice` 与 `updateStatus`。错误和“有新内容，先保留当前编辑”可以同时显示；收起一条说明只清 `notice`，不清 pending、不强制刷新、不解锁 unknown、不提交草稿。更新文案仍取既有共享常量，纯策略 `UsabilityRules.kt` 被实际页面与弹层调用。配对格式/HTTPS失败会在设置弹层内显示，不再只留在被遮住的页面。

## 当前身份的离线文字

冷启动已从当前身份载入草稿、但暂未读到服务端对话时，连接页增加“查看本机保留的草稿”。本页仅从 `EchoState` 获取已载文字，没有读取 vault、旧身份、请求账本或网络。可以查看/复制聊天输入、记忆草稿、跟进文字与心情本机副本；不展示 token、请求 ID 或操作 JSON。

入口与显示必须仍是当前可用 scope / credential-generation / epoch。配对身份须在本机仍激活、未过期且与当前 profile 匹配；离线不能核验电脑端是否刚撤销许可，不把本机副本当在线授权或服务端当前状态；安全存储待核对或停用身份没有入口。配对草稿的 session ID 还须与已激活 profile 的持续对话相符。调试回环保持原地址 scope，只展示该地址本机副本，不冒称已经核验离线服务端身份。

复制按钮再次核对当前访问条件；换身份/代次或失效时旧快照不再渲染或复制。文字按原样保留，未知保存状态仍提示待核对。没有“发送”“保存”“重试”“取消请求”或自动迁移入口，复制也不把文字放入聊天输入。原 R13/R14 的身份隔离、pending 和更新阻挡未解除。

连接页与设置另补静态操作指引：确认电脑回响服务/HTTPS地址，去电脑设置的设备连接区域生成手机连接码；聊天明确提示模型未连接时，回电脑“数据与模型设置”配置并测试。手机不收模型 Key，不按回复关键词推断模型是否可用，不自动开放网络入口。

## 本轮验证与限制

- `verification-jvm-ROUND15.log`：实际 JDK17 / Kotlin2.1.20 Core 编译与 198 项 JUnit（保留 188 项，新增 10 项）。新增测试覆盖错误+更新共同可见、离线配对错误、状态区别、当前 scope 可用性、身份/代次变化拒绝旧快照、原文保留、非当前对话过滤、unknown 冻结体不变、请求 ID 不进入展示、未选心情坐标不伪造中性位置。
- `verification-syntax-ROUND15.log`：42份 Kotlin/KTS PSI 零语法错误；不解析 Compose / Android 类型。
- `verification-static-ROUND15.log` 与 `verification-shared-ROUND15.log`：结构/XML及共享字节检查。

本轮是本机 UI 与只读策略修改，没有网络协议变更，因此未为这两处重复运行历史 HTTP/HTTPS 套件；R14 相应日志仍作为历史证据保留。

**尚未执行 Android SDK / Compose 类型构建、设备界面或真实 Keystore/剪贴板操作。** 纯 Core 和 PSI 不等同平台验收。需要开发同学实际检查：打开编辑弹层后另一端修改/删除时提示仍可见；滚到底部保存失败反馈固定可见；离线冷启动当前身份草稿可复制但不能提交；停止使用/换身份/令牌到期后旧页不再可复制；200%字号、键盘、TalkBack和滚动手势保持可用。
