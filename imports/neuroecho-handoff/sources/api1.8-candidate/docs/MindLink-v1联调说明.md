# MindLink v1 本机适配

当前桌面页面由用户选择“同意并开启读取”后，才会通过主程序读取同一台电脑上 `127.0.0.1:8876/api/v1/state?source=esense` 的实时专注度估计。授权是短时、进程内的，停止或失效后不能读取；读数不记录、不发送模型，不作为情绪或医疗结论。手机页面目前只说明要在设备所在电脑开启，不代表已经远程联通。

读取只接受 1.0 协议、已连接且实时、signal_quality 为 0、来源正确、valid 为 true 且年龄不超过 2500 ms 的值。适配器将请求耗时计入年龄；服务提供 `updated_at_unix` 时，还会检查服务实际更新时间。页面另行计算传输时间，并在超时、断线、隐藏页面、授权过期或读数变旧时清除显示。服务和硬件不在同一台机器时，本机环回接口不会自动可用。

适配层也支持显式指定 `source="personal"`，必须收到 personal_model 且服务报告个人模型已载入，否则返回不可用，不会偷偷回退到 eSense。此选项尚未接入用户页面和主服务路由，因此当前用户页面仍只用 eSense。个人模型分数是未校准的个人自报专注度模型分数，不是情绪解码；`0` 可作为 personal 模型的有效值，eSense 的 `0` 由源服务视为无效。

`tests/test_mindlink_contract_simulator.py` 以模拟 HTTP 传输验证原始接口字段、来源、防回退、断连和时间校验；`tests/test_mindlink_api.py` 与 `tests/test_mindlink_ui.js` 检查授权、撤权竞态和前台过期。由于当前环境禁止监听本机端口，这不是实际 HTTP 网络联调，也没有真机数据。设备到手后请分别验证：队友服务可启动与本机接口返回；佩戴有效时的读数；拔下、信号差、停止服务、授权撤销后的清屏；实际时延和稳定性。
