# 第14轮多端交接

从549份R13冻结源码创建独立副本，保留原并行工作区和所有旧交付。核心变化是同一后端的前台更新发现与安全快照采用。

## 实际行为

1. GET `/api/conversation/changes`返回9域失效向量、服务/持续对话身份、opaque cursor。首读或游标太旧/超前/epoch变化要求全量重读；不会返回正文、来源或令牌。到期跟进、关心边界和分段可见性也可发现，不依赖用户再写一条数据。
2. Web约15s、iOS约15s、Android约10s前台检查；后台停，单飞、有限读等待与退避。先changes→各域快照→changes(原cursor)复核稳定，才一次替换和采用第一份cursor。未知域、格式/身份不匹配、失败均保留原游标，不把GET当写入成功回执。
3. 编辑/上传确认/活动聊天/原unknown保护延续；有更新时明确提示，结束编辑后安全重读。原草稿与请求身份保留，不能自动重发或换ID。iOS/Android的scope与generation隔离继续有效。
4. 完整替换传播删除与来源撤回。Web稳定发布推进读取epoch，废弃旧Today/任务/资料/下一步请求，并同步当前书签/动作DOM；资料摘要更新不会替换模型设置草稿。分段GET也不能复活较旧呈现。
5. 本机owner与配对入口权限保持。远程仍拒绝CLI、系统动作、硬件、模型设置及管理；changes中出现actions域不授权手机调用动作API。

## 验证与接手

最终783 Python +40子测试、568 Web/H5、49桌面Node通过；共享16项与API导出一致。API1.7.0实际92paths/103operations/55typed JSON200。初次全Python中唯一个失败是新增必需module后合成packager seed未补，修fixture后完整重跑通过。

iOS新增Foundation/实际Store宿主/两个真实URLSession设备客户端的临时HTTPS流程，Android新增Core/实际EchoApi与ChangeCoordinator双设备HTTPS流程；详见各端本轮验收。没有手机SDK、真实安全存储或设备安装验收。临时CA仅在测试会话/子进程信任，未安装全局信任。

Web/H5浏览器验收使用独立临时数据和合成peer操作；截图/JSON在外层“念响-第14轮验收”，具体最终状态由同级交付说明定位。没有模型调用、用户真实资料或新增账号授权。Mac最终App GUI和Windows组装由各自报告单独说明，不能用后端启停替代窗口证据。
