# 团队整合源码候选：变更与验收边界

2026-10-30。此目录由冻结的 R14 源码独立复制并整合，不改变原项目、运行服务或个人数据库。`shared/release.json` 是本候选的状态；`历史R14-release.json` 和旧轮文档仅记录历史。

## 这次合入

- 恢复已识别的当轮明确拒谈保护：相关历史、记忆和资料片段不用于该轮模型上下文，也不通过来源查询工具传出。它不是通用语义理解，也不保证自动永久识别一切未来表达。
- 恢复远程模型 HTTPS、本机 HTTP 边界、拒绝自动跟随重定向和跨地址复用已保存密钥的保护；飞书 CLI 使用当前用户目录而不是固定机器路径。未接触现有凭据，本次未验证真实模型或账号。
- 合并旧版静默设置；旧版“少主动问”和“暂停通知”合并到当前统一边界，可能比原设置更保守。原记录保留；删除对话时只清理对应记录。
- 同一持续对话中的普通生成请求由 SQLite 原子判定；繁忙时后到请求持久拒绝而不执行。客户端只在请求 ID、对话 ID、unknown 状态和特定错误码全部吻合后恢复草稿，需用户手动使用新 ID 发送。旧本机调用若没有请求 ID，断线重发无法去重。`unknown` 其他原因不代表未执行。
- 后端可在忙时优先处理已识别的明确静默或安全求助；但网页和手机客户端在已有未确认请求时可能阻止新文字送达，不能保证自然语言优先路径实时可用。Web/H5 为原未确认请求提供停止请求入口，停止请求本身不等于确认已停止；已有的独立关心设置仍需服务端回执。
- Web/H5 本地文件支持 Word 正文预览。Word 二进制会先发至运行服务所在设备的内存中解析，用户确认后才将文本作为来源；损坏文件和不支持的内容会提示失败。已配对的其他设备上选择文件时，服务所在设备并非选择文件的设备。
- 设置加入心情表达实验，Web/H5 与原生源码的实验状态只保留在当前界面；它不是正式心情记录，也不使用脑电判定情绪。退出后清理；各平台仍需真实交互验收。

## 已验证和待验证

- 修改契约版本前，合成数据后端回归 869 项及 40 个子测试通过；2 项需绑定本机 TCP，受本次环境限制未运行。API 1.8.0 的契约快照和相关回归另行检查。
- Web/H5 与桌面 Node 自动检查 663 项通过；为脚本和模拟检查，不等于浏览器视觉或触控验收。
- iOS Foundation 与宿主 Store 检查、macOS SwiftUI 宿主类型检查通过；Android JVM 检查中需要监听 TCP 的用例无法运行，Kotlin 语法解析通过。均不等于 iOS SDK、Android Compose 构建或手机安装。
- 未在本候选重新验证真实 DeepSeek、飞书等账号、浏览器、手机 HTTPS 配对、通知推送、Windows 可执行文件或扬声器。当前服务未重启或更新，历史 R14 的可执行包不包含本候选更改。
- MindLink 真机由队友后续联调；当前只可解释为专注度信号，不能宣称情绪解码。Rokid 为待联调框架。

## 发布和数据

源码包排除私有数据库、模型设置、账户凭据、TLS 私钥、虚拟环境和构建缓存；安装依赖、配置模型及需要的权限均由使用者在目标设备单独完成。R9 历史完整材料含个人截图、录屏和第三方逆向资料，转交前需逐项检查隐私及使用权。单机前台同步不是云端同步或后台推送；请勿直接把本机 owner 服务公开到公网。
