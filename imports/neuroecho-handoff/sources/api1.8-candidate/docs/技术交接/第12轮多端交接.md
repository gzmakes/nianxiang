# 第12轮多端交接

R12从冻结R11复制，未覆盖原始并行工作区或此前交付；当前新增范围是显式设备朗读和Mac自包含分发。API保持1.5/88paths/98operations；F5、来源撤回、记忆CAS、聊天/心情未知账本均保留。

## 朗读

Web/H5使用本机中文voice，明确要求localService=true；Android显式选已安装、无网络要求的voice，禁止setLanguage触发下载/默认远程回退；iOS使用可替换的AVSpeechSynthesizer driver。只读当前显示parts，不替换成隐藏的原text；pending/本人输入不允许。所有回调绑定本次播放身份；后台、内容、对话/服务、话题改变会停止。Web连接/搜索/弹层也停止；不自动恢复或播放。

Android初始化/入队各10秒，播放按字符估算且≤5分钟/段，每段≤600 UTF16字符；无回调超时如实失败。stop ERROR/异常保持“停止尚未确认”，禁止新引擎叠播，保留再停入口。iOSController也有超时/未确认停止保护。Web有开始/完成watchdog；引擎不支持时可继续看文字，不把入队当声音已听见。

Web“生成语音”只有服务明确声明能力才显示，不支持的平台不出现假按钮；这条路在服务Mac生成WAV，与设备直接朗读分开。实际IAB没有可用本机中文voice，已如实验到不可用；Mac服务WAV实际生成且audio paused=true/autoplay=false，未验证扬声器。

## Mac分发

旧开发指针包仍可构建；新arm64便携包内含官方校验的Electron/Python、锁定依赖和完整许可证，不依赖外部venv。desktop bootstrap在导入服务前将DB/模型设置指向私有app profile，运行时不写签名包。拒绝借用未知占用端口，只停止自己拥有的子进程。候选已搬移到独立中文空格路径，以包内Electron Node/Python实际启动HTTP、退出、重开并检查包体不变；最终交付以同级 `macOS组装验收-R12.json` 为准。GUI仍因Mac锁屏未验；非Developer ID/公证/其他Mac或Intel验收。

只用自建临时DB、合成文字/文件和已有模型配置，不接触用户真实资料或新增账号。两轮明确先倾听后，模型未拆任务；用户邀请才给建议。真实文件选择器选取round12-synthetic-background.txt，原文预览后确认，模型准确复述松果小站、首演范围、今晚优先级，指出资料是虚构且与前述建议不同。4个model.success、0fallback；任务/跟进0。接入后6条候选理解在明确撤回后为0，sources=0，持续对话不变；已显示聊天仍保留。WAV控件与手机版390×844另外截图；实际audio从播放0.215s切页后暂停于0.239s、未结束，返回不自动恢复，仍非扬声器验收。一个合成案例不代表真实用户满意度或所有连接器成功。
