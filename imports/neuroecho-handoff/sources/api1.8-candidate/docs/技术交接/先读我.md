# 开发交接先读我 · Round 8

本包是一套继续开发的原型源码。Web/H5 可在本机运行，macOS 为本机开发版；Windows 已提供便携组装方案，未在 Windows 运行验收。iOS/Android 是真实原生工程，尚无 IPA/APK。不得仅凭源码或宿主测试声称各端已完成。

1. 先读根 README 与 SOUL.md，确认单一持续对话、温和陪伴、先预览再确认、未知结果不盲重发。
2. 复跑本端 README 的检查。iOS/Android 本轮按用户要求不安装 SDK；可交给开发同学继续，但先完成平台构建和设备验收。
3. 阅读多端同步与架构方案.md；共享颜色/首批文案/新偏好默认值已接入，布局和业务交互仍要各端负责人同步。
4. 新机器配置自己的模型与来源；本包不包含私人数据、密钥、既有账号授权。当前个人服务不直接开放网络。
5. 验收记录见本端 README/日志及第8轮开发与验收.md。更早报告标注为历史快照，不以旧缺口或旧测试数量代表本轮。

所有端保留同一 API/contract/release 版本，先在同一 Git 仓库协作。源码压缩包只是冻结交接快照；不要用多个 zip 长期分别维护。
