# 第13轮多端交接

本轮从R12冻结清单499份源码另建副本，保留原并行工作区及R12。新范围是手机安全连接同一后端、原身份恢复，以及Web/H5本机设备管理。不是账号系统、公开部署或实时云同步。

## 真实行为

1. 本机设置先展示personal_core完整范围。确认后创建一次显示的7天设备码；刷新/隐藏/离开清除码的显示，列表不返凭据或哈希。明确收回只阻止新请求，不伪称回滚已开始操作。
2. 手机填写HTTPS地址和设备码。先GET配对身份、再核对唯一对话，安全存储成功后才激活；失败保留原连接。请求带不可变Bearer和实例头，禁止重定向或HTTP降级。
3. 数据按origin、service_instance_id、conversation_id、device_id、credential-generation隔离。切换保留原unknown精确正文与请求ID；恢复本人旧连接须再验证同身份，不自动POST。401清理精确凭据；实例409只停用隔离；403不冒充撤销。迟到回调不能清新连接。
4. 远程入口默认关闭。显式TLS入口与本机入口在同一worker共用一次lifespan/DB lease；所有listener排空才释放lease。远程以进程内可信principal标识，不信任转发头。按method/path默认拒绝，所有资源和SID绑定发证时唯一对话；响应发送前重核撤销。
5. 配对可用聊天、记忆CAS、心情账本、所选文件内容预览/确认/撤回和被动跟进。CLI/账号/模型配置/真实动作/硬件/设备管理在远程拒绝，安全来源目录不探测电脑CLI。

合同与开发入口详见 `设备连接API-R13.md`。没有本轮真实用户授权、账号、TLS全局信任或个人资料变更；临时TLS信任只用于隔离测试进程/测试URLSession。

## 验收层次

完整Python、Web和共享一致性以本轮最终日志为准；API1.6.0的91paths/102operations/54个typed JSON200由实际服务导出。iOS的Foundation/SwiftUI宿主/假Keychain与真实URLSession、Android的纯Core/假Vault/JCA与真实Kotlin HTTPS只证明对应源码路径；没有手机SDK、Compose类型编译、IPA/APK或真实设备安全存储验收。

Web与390×844 H5实际用隔离空数据生成测试设备码，分别离开设置/关闭sheet后码字段从53字符变为不存在，返回不会重新显示；确认收回并核对两个测试设备均revoked。截图/JSON位于交付外层的“念响-第13轮验收”目录，由本轮外层交付说明定位，不是本文件的相对路径。未创建用户消息、记忆、心情、动作、跟进或来源；浏览连接目录仅检查可用性状态，没有新登录或读取文档。验收后只停止本轮确切QA进程。

本轮未重复R12真实DeepSeek合成案例与系统WAV，不把旧证据写成R13重验。朗读规则继续保留：Web/H5对话题/来源弹层等视图切换停止；原生按当前可见消息、后台和上下文策略停止，不承诺所有原生sheet出现都会停止。

## 多端接手与未完成门槛

- 原生包是可继续开发的工程，SDK/真机安装仍按用户决定未做；原生README/ACCEPTANCE-ROUND13列明命令和边界。
- 桌面包统一从同一R13冻结源组装，默认无模型配置、不带用户历史；同级macOS/Windows组装报告分别说明源哈希、runtime、许可证和运行验收。
- 主体验仍为一个人一条持续对话。配对同一后端不等于多账号隔离；凭据保护不等于全部本机内容加密；前台读取不等于推送/离线同步。
- 真手机可信HTTPS可达性、模拟器/真机、最终桌面窗口、Windows运行、EEG/Rokid、6–10成人使用和商业验证仍需后续。不能据此称整产品已完成90%。
