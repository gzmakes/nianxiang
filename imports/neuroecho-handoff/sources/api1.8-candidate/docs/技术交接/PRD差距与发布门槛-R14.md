| 目标 | 当前改进 | 仍缺的证明 |
|---|---|---|
| 一个陪伴者、一条持续对话 | 不展示会话编号/恢复/切换；聊天优先、可跳过连接、无需欢迎弹窗；原连续记忆和主动关心边界保留 | 多日真实使用、语言温度与重复度、主动关心接受度 |
| 多端接着聊 | 设备绑定与受限入口、前台更新游标、原子替换、编辑草稿保护；实际宿主HTTPS双设备验证 | 手机可信可达HTTPS、原生SDK/真机、推送/断网/顺序效果 |
| 有用且可操作的应用接入 | 已有真实选择/预览/确认/撤回路径，远程只传用户所选内容；来源撤回与删除通过更新失效传播 | 本轮未重新验所有外部账户或CLI；按用户决定不新增账号授权 |
| 情绪与硬件陪伴 | 用户自报心情、确认记忆、按约定轻问；EEG仅专注度，Rokid保留明确待联调入口 | EEG与Rokid真机、声音/系统权限、不能从脑电推断情绪 |

| 商业化赛道 | 可演示聊天→可修正记忆→明确选择内容→撤回→跨端更新闭环 | 成人试用/留存/价值/成本和付费证据，尚无商业验证 |
