# 第11轮多端交接

## 改动与恢复路径

这是从已封存R10源码创建的独立候选，不覆盖原工作区及另一作者改动。只集成本轮心情账本与本机草稿恢复，共用文案/契约同步；F5、来源撤回、聊天未知账本、记忆CAS、单一持续对话保留。R11前快照和逐文件hash由工作区保存；早期轮次交付可回看，不在本轮反写。

API1.5新增POST `/api/mood-operations`、GET `/{request_id}`、POST `/{request_id}/cancel`；旧PUT/DELETE保留。原始operation_json精确UTF-8 hash绑定id，SQLite同事务写记录和终态。cancel仅hash/kind，不携带日期/正文；预取消挡晚到apply，已applied取消不回滚。终态回执是历史事实，客户端另GET当前记录后再决定状态，旧成功save不复活后来删除的日记。查空不是停止证明，旧无IDpending仅只读核对，不补造标识。

Web/H5关闭旧窗口后的草稿可主动找回；同日当前不同草稿先另存，再复制选中版本；不同源/对话隔离。当前所有普通草稿和SQLite尚未加密，不是正式敏感数据存储方案。

## 多端分工建议

固定共享契约/文案的一位维护者；每端各一位作者，提交时同时列出受影响端。共用按钮改字先改shared，再同步生成；布局与本地权限分别检查。每次合并执行sync/API/stamp/strict与相关端验证，发包固定同一release_id和SOURCE-MANIFEST。功能用能力标志渐进接入，旧后端缺能力不显示假入口或绕过保护。

## 保留的发布门槛

1. iOS/Android：用户暂不安装SDK，只能交源码；开发同学先做SDK构建、模拟器、设备/生命周期/磁盘故障/读屏验证，再谈发布。
2. Windows：便携包仅离线组装，需Windows真机验启动/文件选择/通知/中文路径；Mac本轮GUI待解锁重验，App当前依赖兄弟源码与Python环境。
3. 多设备：当前单用户loopback服务，需要独立HTTPS鉴权/配对/同步冲突协议；不能用开放本机端口代替。
4. 连接：本轮没有新增账号授权或重验真实外部资料读取；CLI只在服务电脑运行，不等于手机也有CLI。Rokid/脑电待联调，专注度不是情绪。
5. 陪伴效果/商业化：仍需要真实用户任务、连续使用和愿意付费的证据。本轮不新增支付或主动消息发送。
