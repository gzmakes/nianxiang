# 第10轮多端交接

R10在R9基线上新增本人手动心情记录，并保留单一持续对话、记忆CAS、资料预览/确认/撤回、daily跟进和F5统一边界。两份原生工程可交给对应开发同学继续开发；**不是各端已完成、原生可安装或“全端90%”的结论**。用户暂不安装SDK，仍没有iOS / Android SDK构建、模拟器或真机验收。

原工程及R9交付保留。R10从隔离基线分块引入心情功能，不整目录覆盖并行作者的旧Models / API / 状态管理；交付路径、ZIP与桌面产物以最终交付清单为准。

## 这一轮可用到哪里

| 能力 | 当前源码行为 | 重要边界 |
|---|---|---|
| 本人手动记录 | 选日期、感受 / 精力两轴、可选文字，明确确认保存；可查看、修改和确认删除 | 默认0/0仍是未选择，不能自动保存成中性心情；一条记录不是全天平均或心理诊断 |
| 日记用途 | 日记默认独立保存，不加入模型prompt、长期记忆、聊天或F5联系许可 | 显式“带到聊天，由我发送”先展示选定内容，仅追加原聊天草稿；本人另按发送才由当前聊天模型处理 |
| 草稿与恢复 | 两原生持久保留文字、位置、已选标记、已读版本和未决写入；按服务/对话隔离 | iOS按日期留独立草稿；Android未提交草稿切日需先保存/明确放弃。均非云端草稿同步或独立加密保险箱 |
| 保存 / 删除回执 | confirmed:true、精确expected_updated_at；保存核对日期 / 坐标 / 原文 / 新token，删除不能只看HTTP200 | 日记版本是opaque ISO token；query中的+00:00须按URL编码保留原值。删除重建后旧token不可复用 |
| 409冲突 | 保留原草稿，读取并展示最新记录，本人明确采用已读版本后再单独确认 | 不能自动换token、覆写别端更新或自动重试 |
| unknown | 超时、解码失败或不匹配回执保留不可变快照，先GET核对，不自动再次PUT / DELETE | 没有日记操作账本。新建unknown读空不证明未执行；删除unknown读空只证明当前无记录，不补造删除回执 |
| 迟到与切换 | 核对origin / 对话 / 代次或操作快照，旧失败和旧成功不覆盖当前界面 | 实际手机后台 / 杀进程与切换地址点按仍需设备验收 |
| 旧能力保留 | 持续对话、搜索/话题/草稿、记忆CAS、完整飞书预览、daily当前次、暂停/恢复/取消、F5共享边界 | passive review_available与contact eligibility分开；边界变化/拒绝/撤源使全部旧许可失效，恢复不补问 |
| 原生主动功能 | 可查看被动待办和设置联系范围 | iOS / Android没有自动轻问、contact claim投递或系统通知，不把许可开关说成已经送达 |

服务合同为 **1.4.0，85条路径 / 95个HTTP操作**；4个Mood操作加在R9接口之上。新能力为 `daily_mood_entries` 与 `mood_self_report_suggestions`。原生本轮只接手动CRUD，不展示未实现的建议入口。后端的有限规则建议不等于读取聊天、调用模型或设备识别；不能据能力键宣称原生已接通。

## 心情实验室的定位

原先“心情实验室”是独立的地图 / 双滑杆表达界面对比与研究背景，不是原生App里的心理练习。本轮**不将其独立产品或HTML页面带进App**。没有参与者结果、疗效数据或设备情绪识别证据；10条合成语句检查也只是工程自检。原生手动记录不声称治疗、情绪推断或改善心理健康。

后续若做陪伴/练习，应先明确本人选择如何使用记录、可跳过/停止、内容来源和体验指标；若主动呈现，再进入现有F5许可/claim流程。不能为心情功能另起计时器绕过静默，也不能把脑电专注度映射成情绪。

## 接手与多端协作

1. iOS先读 [iOS接手](iOS接手.md)，在完整Xcode中构建并验UIKit、模拟器、真机、VoiceOver / 大字 / 键盘、文件和前后台恢复；当前没有IPA。
2. Android先读 [Android接手](Android接手.md)，在SDK齐备后做Compose类型编译、test/lint/assembleDebug及TalkBack / 大字 / 进程恢复；当前没有APK/AAB。
3. 手机127.0.0.1指手机自身，当前后端是本机单用户回环服务。可达HTTPS、身份/配对与安全远程后端仍待做；不能把个人服务直接开放公网来冒充打通。
4. 行为先更新共同API/能力/错误语义，文案与色板经shared生成并接入真实组件，再同步Web/H5、Electron、Swift、Kotlin各自交互。新默认值不覆盖已保存偏好；生成成功不是布局或平台运行齐平。
5. 在最终代码上同步资源/API、stamp Web资产、严格检查，再跑对应回归与实际GUI；冻结后由打包流程生成同版本ZIP/桌面包/hash清单。文档修改阶段没有运行整包。
