# 念响：PRD、Today 与真实操作复核

更新：2026-10-29。本次以用户最新要求为准：**直接聊天、不用欢迎弹窗、只保留一条持续对话，按钮必须有真实后续。**此前欢迎弹窗与多对话入口已撤下。

## 参考与判断

已对照本地 PRD、交接包和 Today 逆向规格，以及用户本次三张截图和约 3 分 30 秒的录屏。录屏重点覆盖右侧 Today／任务／记忆切换、连接目录、飞书 CLI 建立与授权、系统权限提示及连接状态。画面里的“授权成功”只证明该录屏环境的步骤，不能证明本原型已具备相同账号权限。

Today 的可借鉴部分是：聊天持续在场，右侧内容可打开、续接和执行；连接状态、读取结果与执行结果各有反馈。不能只复制卡片外观或把任意跳转当完成。

前轮读取的公开参考：[Today 官网](https://today.ai/)、[能力说明](https://today.ai/articles/capabilities)、[产品介绍](https://today.ai/articles/blog/what-is-today)。这些属于厂商公开表述；本轮主要按用户提供的界面材料与实际原型行为调整，没有重新验证 Today 服务端全部能力。

## 已修复的断点

| 断点 | 本次处理 |
|---|---|
| 欢迎与配置打断聊天、多对话编号暴露 | 取消欢迎与重开；服务端持久固定主对话，客户端不再按旧本地编号分叉；旧数据不删不混入 |
| 连接目录挡住聊天、正常入口仍有演示连接器 | 电脑目录移到右侧；输入＋可进入。正常路径只走真实 sources／preview／attach，读取失败不回退演示资料 |
| Apple 失败假成功、飞书错误异常 | Apple 失败明确返回；实读问候引用实际条目。飞书 CLI 非零退出不可报成功，异常结构与启动错误可恢复 |
| Today 卡只是阅读终点 | 提供续聊、理解、书签、任务和来源操作；无材料时给真实草稿／提醒入口，不凑“0条理解”的建议 |
| 展示 A 建议却可能保存 B | 书签编辑绑定当前卡实际内容，避免异步全局建议覆盖 |
| 待确认任务无法继续 | 先核对现有记录，再提交同一 ID；未知状态只核对，不自动重试外部写入 |
| 保存中取消仍可能继续提交 | 创建回包后再次核对当前操作；取消后不再发 commit；已发出的 commit 不能当作被取消 |
| H5 慢响应覆盖新页面 | Today、来源、记忆与任务使用对话／页面代次检查，过期回包不重绘已离开的页面 |
| 单一对话累计40轮会永久停用 | 改成 UTC 近60分钟40轮滚动额度，入口与剩余额度同口径；旧历史不删除 |
| 书签保存冒出模拟硬件 ACK | 正常流程取消模拟 display 请求；Rokid 和 EEG 真机状态明确待联调 |

PRD 的可纠正理解、确认后执行、重复只写一次和失败／未知可核对仍保留。没有把这次改版扩张成任意命令执行或通用后台任务平台。

## 本轮实际验收

| 操作链 | 结果与证据范围 |
|---|---|
| 本机文件→预览→接入→模型问答 | 浏览器选取自建合成文本，确认接入；真实 DeepSeek 正确回答测试标记。未使用私人资料 |
| Git→指定目录→预览→接入 | 真实 Git 二进制读取临时合成仓库提交；确认后与文件共存，原聊天不变 |
| 新建草稿→保存→查看全文 | 通过实际页面编辑标题正文、保存、展开，内容一致，显示未发送 |
| 待确认项→继续确认 | 以实际 API 预览生成一条待确认提醒，浏览器从 Today 继续确认；原 ID 变 committed，动作数量不增加，real=false |
| 刷新／PC与H5连续使用 | 同一主对话、聊天、来源和任务；隔离库最终只有一条对话。已有用户库迁移演练全部旧 ID 保留 |
| 自动回归 | Python **388 项＋21 子测试**，前端 **308 项**，桌面 **18 项**通过；包括并发主对话选定、滚动额度、状态竞争、取消、草稿保留和迟到回包 |

本轮截图使用自建测试数据库及合成内容，不包含用户的 Today 私人聊天、录屏帧或凭据。录屏仅用于操作分析，未收入分享包。

## 接入的真实状态

本机文件和 Git 已做本轮实际浏览器闭环；飞书前轮已有真实授权、搜索、单篇预览及接入证据，本轮继续保留，并修正桥接失败状态。Notion、GitHub、Gmail 的适配存在，但账号授权和各自真实读取仍需验收；用户选择暂不新增账号授权，本轮没有扩大。Apple 的权限、真实日历／提醒对象写入没有在本轮实际触发。

Rokid 当前只有待联调说明；MindLink 保留显式开启与失效退出，队友设备未接入。脑电不等于情绪识别；本机 Web／H5 不等于真手机访问；源码壳不等于已签名的安装包。

仍需后续完成的门槛是用户愿意授权的账号、Apple 系统对象回查、真手机访问及硬件联调。当前版本不把这些未完成项显示为已接通，也不制造外部简报或后台执行结果。
