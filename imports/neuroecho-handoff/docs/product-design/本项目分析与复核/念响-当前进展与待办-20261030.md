# 念响：当前进展与待办

更新：2026-10-30。依据用户提供的 PRD 0.4、后续明确的情感陪伴／单一持续对话方向，以及当前项目源码和开发记录。本清单不把演示占位、合成数据测试或历史成功记录当成当前真机验收；优先级是开发建议，不代表已经排期。

## 现在已经做到什么

- Web/H5 有持续对话、用户选择回应方式、需确认的记忆与来源管理；本机文件可逐份撤回，飞书正文可在确认前核对。源码和隔离测试不等同于真实账号和模型联调完成。
- 一次及每日应用内跟进有保存、取消和失败核对；Web/H5 中明确的“提醒我……”可以进入需用户确认的草稿。口语时间目前需用户自己选择，代码新增默认关闭的系统通知，需开启并保持对应程序运行；系统实际显示尚待真机验收。
- Web/H5 的本地来源事实可按需核对**逐字出现于已接入快照**的原文。范围只覆盖符合条件的单份本地文本事实；推断、纠正后不匹配、历史合并来源和其他连接器不会猜测原文。文字匹配不证明判断正确。
- iOS/Android 已有原生工程和部分宿主／JVM 检查；每日跟进当前在手机端只查看，操作需去 Web。原生飞书完整预览的源码和合成检查已补，仍需目标平台构建及真机验收。

## 仍未完成

| 优先级 | 事项 | 当前缺口与验收结果 |
|---|---|---|
| P0 | 真正的陪伴闭环 | 当前以隔离的合成模型测试为主。需用真实模型完成连续对话→确认偏好→纠正→后续回应改变，并由真实用户评价自然度、分寸和理解准确性。模型代码存在不等于当前 DeepSeek 请求可用。 |
| P0 | 来源与理解的真实验收 | 本机文件、飞书已有代码；当前飞书账号的授权状态、真实单篇读取、确认、对话与撤回尚未本轮实测。原文核对目前只覆盖部分本地事实，并非每条理解或每条回答都有可核对的证据；旧书签的 `source_quote` 不一定是原文。 |
| P0 | 手机真正能安装使用 | iOS／Android 有原生源码，但未通过目标 SDK 编译、模拟器或真机安装。需要检查页面、权限、可访问性、网络错误及真实请求；仅做宿主／JVM 测试不能证明 App 可交付。 |
| P0 | 安全的多设备连接 | 后端目前以 Mac 本机回环为基础；手机与电脑安全配对、身份认证、HTTPS、同步与断线恢复尚未形成完整方案。一个本机数据库中的持续对话不等于跨设备同步。 |
| P0 | 桌面实际打开与完整交付 | 已有 Electron 源码和窗口逻辑测试；最新修改后的实际窗口启动和用户报告的打不开需要重验，签名、公证和可分发安装包尚未完成。 |
| P1 | 主动跟进与通知 | 应用内一次／每日跟进和运行期间的可选系统提醒已有代码；基于上下文自动发起的关怀、手机端每日管理、程序关闭后的系统通知、送达／阅读回执及真实设备验收尚未完成。自然表达如“过几天再聊聊”尚不能可靠自动转草稿。 |
| P1 | 记忆长期体验 | 需要更完整地处理经历发生时间、时效、冲突、话题边界和用户纠正；“今天别再提 X”这种可到期规则还没有完整落地。不得以自动推测冒充用户确认。 |
| P1 | 隐私和数据生命周期 | 最终发往模型的字段逐项审阅、完整导出／备份恢复、外部服务留存与删除边界尚需完善。本机模型配置目前属于演示实现，密钥以本机受限权限文件保存，尚非系统钥匙串方案。 |
| 待设备 | 脑机与 Rokid | MindLink 专注度桥有模拟质量与时效检查，队友设备和噪声条件待真机联调；不能把专注度当作情绪解码。Rokid 按用户决定暂做框架，型号、手机系统和 SDK 之后确认。 |
| 产品验证 | 用户与商业化 | 留存、佩戴成本、真实付费意愿及“有／无硬件”的体验差异尚无充分验证。支付按既有决定暂缓，不因技术可做就自动接入。 |

## 建议的下一步

1. 在允许启动本机预览的环境，完成一条真实对话与一份用户选定资料的端到端验收：预览→确认→提问→核对依据→纠正或撤回→再次提问。
2. 让一台目标手机完成原生构建、安装及安全连接，再扩到另一平台；现有两端源码继续同步，不宣称已有安装包。
3. 队友带设备后验证 MindLink 实时值、质量不足、断流、停止与降级；先不宣称情绪识别。
