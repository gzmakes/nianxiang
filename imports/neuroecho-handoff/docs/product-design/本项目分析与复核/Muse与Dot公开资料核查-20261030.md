# Muse、Dots 与开源参考（2026-10-30）

本记录用于指导念响的设计，不表示第三方项目已经集成或实测。按官方资料、第三方实现和本项目建议区分。

## 官方公开材料

- [Meta Muse 产品介绍](https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/)：个人目标、持续任务、授权和操作确认的产品描述。
- [Muse 安全架构](https://research.meta.ai/blog/security-and-safety-for-ai-agents-our-approach-with-muse)：隔离运行环境、凭据隔离与独立权限检查的设计；不能据此说本项目已有同等隔离。
- [Muse Gadget SDK](https://github.com/facebookincubator/muse-gadget-sdk)：设备能力、配对和消息协议参考，不能直接当作 MindLink 或 Rokid 的驱动；源码和素材依赖分别核对许可。
- [Muse Glimmer 模型](https://huggingface.co/meta-models/Muse-Glimmer-30B)和[运行示例](https://github.com/meta-models/meta-oss-cookbook)：开放权重和开发示例，不是完整 Muse 消费者产品源码，也不代表适合本机实时中文陪伴。
- [OpenAI Dots 产品介绍](https://openai.com/index/introducing-dots/)：持续工作、用户可查看进度、按权限使用应用的产品思路；本次未找到 Dots 完整产品源码公开声明。

## 独立社区项目

- [nanoMuse](https://github.com/nano-muse/nanoMuse)：作者描述跨端客户端、relay 与可编辑记忆；GPL-3.0-or-later，若复制和分发代码需评估许可证义务。能力未由本项目实际测试。
- [CopilotKit OpenMuse](https://github.com/CopilotKit/OpenMuse)：MIT 项目，任务、浏览器和进度交互可参考。非 Meta 官方项目，能力未由本项目实际测试。
- [thinkwee OpenDot](https://github.com/thinkwee/OpenDot)：MIT 独立项目，任务、模型与连接器组织可参考，非 OpenAI 官方项目。
- [DSH 版 opendot](https://github.com/itumor/opendot)：展示 scheduler、memory、policy 和 events 等模块划分；本次未确认明确许可证，先研究设计而不复制代码。

## 对本项目的取舍

先维护唯一可复现的源码与验收链；在现有 DeepSeek 适配上改善单一持续对话、记忆纠正、经同意的跟进和动作回执。脑机仅处理已提供的专注度与数据质量，Rokid 保持待设备联调。远程设备连接需要单独设计身份、配对与传输，不直接开放本机个人服务。
