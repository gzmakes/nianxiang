# 股民情感陪伴＋EEG：机会审核与可验证的产品边界

研究日期：2026-10-27。本文是PRD候选研究，不代表已选定方向，不提供个股、仓位、买卖时机或收益建议。未读取或记录私人聊天中的姓名、住址、电话。朋友愿意参与是访谈/试用意向，尚不是需求、效果或付费验证。

## 核心判断

**值得加入候选，但应拆成两个业务。** 成人投资者自己的“交易纪律与复盘伙伴”有具体时刻、可回顾的事件和软硬件展示机会；“向量化机构出售脑电另类因子”则是另一种数据产品，其标签、客户、授权、样本规模与验收标准完全不同。前者的用户信任不能默认转化为后者的数据资产。

真实 neurofinance 研究支持“金融决策与生理/神经信号有关”，并不支持“涨跌时脑波最好测”“平静脑波就是高手”“收集一群股民EEG就能产生可交易Alpha”。尤其2026年已有专业交易者现场EEG研究，发现恰好比这种直觉更复杂。

## 一、逐条审核朋友的假设

| 假设 | 当前判断 | 应替换成怎样的可验证问题 |
|---|---|---|
| 涨跌期脑波波动最大、最容易检测 | **未证实。** 生理反应可随市场事件变化，但没有找到比较多种日常场景后证明“交易涨跌是最容易解码EEG”的证据；波动大也可能是眨眼、皱眉、头动 | 特定设备在用户坐定的模拟任务中，能否得到稳定、可解释且领先于干预时点的信号？ |
| 高手脑波更平稳 | **不能当规则。** 少量老研究观察的是部分自主神经反应与经验，非普适EEG结论；新研究中更成功交易前反而有较大任务参与度上升 | 与同一人的个人基线比较，哪些变化与他自己确认的状态或流程违规相关？ |
| 能识别情绪，就能避免亏损 | **两次推断均需验证。** 生理唤醒≠特定情绪；提醒改变行为≠改善风险调整收益 | 能否减少用户事前定义的流程遗漏，同时不增加打扰、过度交易或错误自信？ |
| 脑电能成为机构另类因子 | **有研究线索，无产品验证。** 个人状态、本人某笔执行质量、未来市场收益是三种不同目标 | 它能否在公开行情、订单行为和已有情绪指标之外，提供可交易时点获得的独立信息，并覆盖全部成本？ |
| 一个股民愿意戴设备，市场就成立 | **只能证明招募入口存在。** 高波动时期愿试不等于长期佩戴、付费或同意对外供数 | 能否跨平静日/波动日持续用？愿为记录、流程陪伴还是预测付费？被告知不用脑电也能做后是否仍选择硬件？ |

## 二、原始研究怎么说

### T01：Lo 与 Repin，2002——经典论文主要不是EEG

10名专业证券交易者的实盘研究记录皮电、血容量脉搏、心率等生理信号。市场事件和高波动期与部分反应有关；5名高经验者在某些瞬时事件上反应较少，但高波动也引起他们的显著反应。经验由主管访谈区分，并非按“脑波平稳程度”定义高手。**它不能用于声称已验证消费级脑电能识别零售投资者情绪。** [MIT作者原始论文](https://web.mit.edu/Alo/www/Papers/lo_repin2002.pdf)

### T02：Lo、Repin 与 Steenbarger，2005——情绪与表现有关，测量是问卷

80名参与者来自五周日内交易培训项目；研究使用每日情绪自报和损益记录。强烈的正/负情绪反应与较差表现相关，未发现统一的“交易者人格”。末次问卷有效回复33人，存在流失。**不是EEG研究，也不能从关联推出“把情绪压低就能盈利”。** [MIT作者论文](https://web.mit.edu/Alo/www/Papers/AERPub.pdf)

### T03：Coates 与 Herbert，2008——激素研究不能换成脑波结论

伦敦男性交易者的实地研究采样内源性类固醇，发现晨间睾酮与当日盈利、皮质醇与市场/损益波动相关。它提示生理状态值得研究，**所测不是脑电、不是设备情绪分类准确率，也不是改善收益的产品试验。** [PubMed原始摘要与DOI](https://pubmed.ncbi.nlm.nih.gov/18413617/)

### T04：2026年新研究——专业交易者可穿戴EEG实盘，但不是“越平稳越赚钱”

NBER工作论文《Measuring Neural Engagement in High-Stakes Trading》，2026年6月发布、7月修订，尚未经同行评审。本轮成功获取官方全文。16名同一A股自营公司日内交易者，用 NeuroSky 单通道记录，关联9,544笔成交。研究以 beta/(alpha+theta) 构造 Engagement Index：同人同小时内，更成功交易前30秒的指数上升更大；背景高指数没有正向预测力。作者承认关联性、机会质量混杂及运动伪迹不能完全排除。**任务参与度、情绪稳定、零售投资者能力与未来市场收益不能互相替代。** [NBER论文主页](https://www.nber.org/papers/w35345)、[官方全文](https://www.nber.org/system/files/working_papers/w35345/w35345.pdf)

补充研究解释（我们的推断）：数千笔成交不等于数千名独立用户。单公司、特定策略的观察适合生成假设；让普通投资者保持某个指数、按指数暂停或执行交易，均需要新的干预研究，不能直接继承论文结论。

### T13：经验组与新手组EEG——确有研究，样本非常小

Dorow等的2017作者稿、2018期刊论文，实验样本为12名男大学生与5名男性专业交易者，考察处置效应、EEG和心率变异。研究发现专业组更可能避开处置效应，较高脑电活动/HRV与收益正相关。**不是“高手脑波始终低/稳”的依据；实验性小样本也不能定义消费者分层。** [作者存档全文](https://mpra.ub.uni-muenchen.de/83354/1/MPRA_paper_83354.pdf)

### T05：机构脑信号预测并非毫无研究，但不能把fMRI成果移植成头带能力

PNAS 2024论文分析34名专业投资者、44个历史匿名投资案例，使用fMRI的伏隔核反应做案例层面的预测并交叉验证。作者报告神经信号比其显性判断更有预测信息，也承认案例少、可能无意识识别等限制。**这是fMRI与特定实验，不是EEG头带、在线真实市场前瞻交易或可销售Alpha系统。** [大学托管期刊全文](https://pure.eur.nl/ws/portalfiles/portal/184835268/van-brussel-et-al-2024-brain-activity-of-professional-investors-signals-future-stock-performance.pdf)

## 三、痛点有依据，但竞品已经在做

### 不应把“更多打开、更频繁交易”作为成功

英国FCA的9,000余消费者在线实验考察闪烁价格、推送、排行榜和积分抽奖，发现数字互动设计能够改变交易频率与风险承担；影响因人群和设计而异。它是英国实验环境的证据，不能外推为中国股民患病率或某个EEG方案的效益。[FCA研究，2024发布、2026更新](https://www.fca.org.uk/publications/fca-research/research-note-digital-engagement-practices-trading-apps-experiment)

研究推断：机会可能是“减少自己不想要的行为”，而不是提供更多行情刺激。行情推送与情绪伴聊如果不断把人拉回盘面，可能与用户利益冲突。

| 替代方式 | 已有能力 / 证据 | 我们必须证明的额外价值 |
|---|---|---|
| 纸面/表格的盘前预承诺、盘后日志 | 低成本，用户自己定义流程，无需佩戴；属于产品基线，不宣称已验证疗效 | 少写、好回顾，并在用户允许的时刻提醒，而非多一个负担 |
| Tradervue | 已有交易与日志备注搜索。[官方帮助](https://help.tradervue.com/article/3459-search-your-trades-and-journal-notes) | 不重复造通用交易日记；对齐自定规则与一次真实事件 |
| TradeZella | 官网已宣称风险Agent、FOMO/情绪识别、盘前准备/盘后复盘和自定义Agent；利用日志、点击节奏与交易频率。[官网](https://www.tradezella.com/) | 我们接入的生理信号是否比行为数据有增量？以上为厂商能力宣称，尚未独立测试可用性/效果 |
| Tradovate Prop | 2026-06的官方说明已有手动账户冷静锁与风险参数锁；两者不同，且该文限定模拟评估账户。[官方说明](https://prop.tradovate.com/blogs/manual-lockout-tradovate-prop) | 预承诺无需脑机接口；不可把“提醒暂停”包装成券商级真正封单/止损，更不能误接会平仓的控制 |

## 四、C端自我管理与B端另类因子是两门生意

| 项目 | C端：自我设定的流程伙伴 | B端：神经/生理另类数据或机构研究服务 |
|---|---|---|
| 谁付钱、谁受益 | 同一成人用户通常两者重合；愿付费仍待验证 | 机构研究/风险/数据部门；被采集者未必受益，需独立设计权益 |
| 核心目标 | 记住自己的承诺、辨认状态、少一次流程遗漏、完成复盘 | 新信息是否能改善模型、执行质量或风险监测；三种目标需分别定义 |
| 典型交付 | 用户确认的状态、日志、解释清楚的提醒、模拟流程卡 | 可审计的数据集/流、时间戳、质量指标、授权链、研究评估 |
| 短期验收 | 可用性、规则遵守、误提醒、佩戴负担、复盘完成；不是收益 | 严格前瞻/跨时段测试、独立增益、覆盖/延迟/成本；不是一次拟合显著 |
| 竞争替代 | 自报、定时器、操作事件、交易日志、券商自设限制 | 行情、订单流、公开情绪与已有另类数据，以及机构内部行为数据 |
| 当前阶段 | 可以作为黑客松候选，先在模拟环境验证一条流程 | 客户需求与可用数据均未验证，只适合作为独立研究设想 |
| 数据权利 | 原始信号、交易日志和个人状态首先服务本人 | 新接收方、新目的要另行论证与授权，不能藏进C端默认条款 |

我们的商业判断：以“帮助你保护自己的流程”为承诺，却暗中把你的急躁、交易节奏卖给其他市场参与者，会同时破坏信任与研究样本。若未来确有机构项目，应独立招募、独立说明利益与风险；不能将售数当成C端天然第二曲线。

## 五、若做机构研究，必须先排除哪些假信号

以下是方法建议，不是已完成分析。

1. **先分清预测对象。** 预测本人是否违规、本人下一笔执行结果、股票未来价格、总体风险偏好，所需标签和有效时点不同。别把“识别刚亏钱”当“预测即将亏钱”。
2. **时间泄漏。** 事后损益、成交后脑电、用全天数据归一化、向前后双向滤波、未来数据挑选事件，都可能让事前不可得的信息进入模型。窗口应只含真正可用的过去数据；原始设备时间、服务器接收时间、事件时间分别记录。
3. **内生性与反向因果。** 更好的机会可能同时引起更高参与度和较好结果；行情已跌导致紧张，而非紧张领先行情。用户有持仓、是否操作、收到何种提示均会改变脑电，提醒本身也会改变后续标签。
4. **样本与相关性。** 高频秒级窗口来自同人同日，不能随机切片成独立训练/测试；至少按人、按日期和市场阶段隔离，并以新的真实前瞻时段核验。不能把股票案例×参与者扩成独立市场样本。
5. **公开信息基线。** 必须比较行情、波动、时间、账户行为、点击节奏和自报。若EEG只是价格波动的慢回声，就不证明另类信息价值。
6. **指标失配。** 分类准确率不是收益；降低提醒次数也可能漏掉关键时刻。目标需包含误报、漏报、延迟、实际用户行为与成本。
7. **部署成本。** 设备、维护、佩戴/接触失败、掉线、同步、校准、隐私与授权、样本补偿、数据清洗都进入成本。机构不会仅因为数据“新奇”就持续采购。
8. **泛化与行为变化。** 纸面交易、竞赛刺激、实盘有显著差异；不同策略、年龄、睡眠和设备变化使统一阈值脆弱。长时间平静可能来自休息、无持仓或不关注，不能标“专业”。

## 六、官方规则对产品边界的直接影响

### 数据用途：不能把“匿名处理”当作万能开关

《个人信息保护法》区分去标识化与匿名化：前者不借助额外信息不能识别，后者不可识别且不能复原。删姓名、换ID或加密不自动达到匿名化。神经信号结合健康/交易账户等信息，应按实际用途与风险判断敏感性；相关敏感处理、对外提供与自动化决策有特定要求。**PRD应分开写本人服务与对机构供数，采用目的限定、最少保存、可撤回及删除路径。** 这不等于“获得勾选即可任意售数”。[官方法律全文，重点第23、28—30、55、73条](https://www.samr.gov.cn/wljys/gzzd/art/2023/art_3ef1e889c1e644d4b65b5f5c7f432386.html)

### 功能边界：写“情绪陪伴”不改变实际提供的服务

证监会修订后的公开规范将选证券品种、预测具体证券走势、给出买卖时机等软件功能纳入相应投资咨询监管；不具备这些功能的信息汇总/历史统计有区别。是否构成相关业务取决于实际功能和经营安排，**一句“不构成投资建议”不能替代边界设计**。黑客松版应限定自定流程、情绪自报与复盘，不输出股票或时机判断、不代下单、不承诺收益；上线前仍需按最终功能核查适用要求。[证监会修订文本，第20—30页相关规定](https://www.csrc.gov.cn/csrc/c101950/c1047975/1047975/files/%E9%99%84%E4%BB%B61_%E4%B8%AD%E5%9B%BD%E8%AF%81%E7%9B%91%E4%BC%9A%E5%86%B3%E5%AE%9A%E4%BF%AE%E6%94%B9%E7%9A%84%E8%A7%84%E8%8C%83%E6%80%A7%E6%96%87%E4%BB%B6.pdf)

### 脑机研究：可自主退出与诚实表述要进入体验

科技部公开的《脑机接口研究伦理指引》强调知情同意、神经数据保护、自主性和准确发布研究；增强类研究尤其要谨慎处理竞争、公平与决策替代。它是科研伦理指引，并非把所有展示一概判成临床试验；若开展正式人体效果研究，应依具体方案落实适用审查。**竞赛中要区分真实采集、回放和合成，参与者可随时结束，不把指标描述为心理诊断或交易能力评定。** [官方指引PDF](https://www.most.gov.cn/kjbgz/202402/P020250729548085721952.pdf)

## 七、适合写进PRD的候选卡

**暂名：止一拍 / 交易时刻伙伴。** 服务有自我约束意愿的成年活跃投资者；既有交易行为、愿意事前定义流程，并同意尝试短时佩戴。普通长期定投者和单纯追求荐股/暴富的人，不应被默认当高需求用户。

**用户问题假设：** “行情或损益变化时，我容易忘掉自己事前说好的流程；普通提醒不了解我刚经历什么，盘后才意识到刚才没有想清楚。”本轮找到相关机制研究与替代产品，尚无我们的用户访谈或中国市场付费证据。

**一条闭环：** 盘前选择自己的流程 → 模拟事件发生 → 有效生理信号作为弱证据，结合用户自报与流程事件 → 实体终端询问是否开始事前选好的短暂停顿/记录 → 用户确认 → 完成一张复盘卡 → 用户纠正Agent的解释。

**EEG为何存在：** 探索它是否帮助用户发现自己未主动表达的状态变化、是否更愿启动自定流程；必须比较“只有自报＋事件”“加真实EEG”两组。不是用研究中的EI高低自动判断现在该买卖或该休息。

**P0可验收能力：** 真实信号与质量状态可见；物理确认/拒绝；本地模拟事件；自定流程；一张有时间与来源的事件回顾；删除本次会话。模型解释只引用用户已确认的信息，禁止把一次信号跳变写成“你现在恐惧/你是韭菜”。

**不进入黑客松闭环：** 真金白银实验、行情预测、券商订单执行、对外出售个人信号、高手排名、收入/收益承诺。真实交易控制的容错与责任远高于本地模拟待办，不能为了展示“Agent能行动”强行接入。

**评测目标（待团队确定数值，不填假成绩）：** 信号有效窗口比例、连接/校准时间、错误心理断言数、误打扰数、用户拒绝后的停手率、事前自定流程遗漏率、复盘完成率、愿意下次佩戴与付费理由。真实信号质量及硬件反馈可现场验证，行为改善需后续样本；短期损益不是本次成功指标。

**需要验证的淘汰条件：** 提示反而增加回看行情/操作冲动；不戴也同样有效且用户不愿戴；无法取得可靠实时信号；用户只肯为预测付费；只能以出售数据补贴却没人同意供数。任一命中都应改定位或降低假设强度。

## 与其它候选放在同一把尺子上

这是有趣、有原始研究支撑、能具体展示“分寸”的候选：它能回答为什么某个时刻主动、为什么先询问、为什么不替人行动。它的缺点同样明确：竞争已有、信号解释难、金融后果敏感、设备未知、付费动机尚不清楚。适合继续访谈与概念原型，不足以凭朋友一句认可就覆盖原来的候选分析。
