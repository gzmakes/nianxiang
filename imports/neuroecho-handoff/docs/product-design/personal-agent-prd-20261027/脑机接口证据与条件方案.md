# 脑机接口 × Personal Agent：PRD 决策证据

核查日期：2026-10-27（Asia/Shanghai）。本文件为研究与产品建议，不是已实现能力或医疗效果声明。用户尚不能提供设备型号、SDK、到货时间；因此所有设备接入均为条件方案，不能在 PRD 写成已确定。未操作用户浏览器已有标签页。按 web-access skill 完成检查：Node 可用、Chrome CDP 未连接；公开资料使用搜索发现＋官方页面/论文原文读取，不依赖用户登录。

## 一句话判断

**保留真实脑机作为核心，但将它的价值从“替用户定义情绪”转成“让用户与 Agent 共同观察、调节一段当下体验”。** 最稳的初始闭环是用户主动开启的 3–8 分钟恢复/专注陪伴：实时信号→质量检查→相对基线反馈→用户确认体验→调整声光/宠物表现→结束并留下用户认可的记忆。硬件不是装饰；它在闭环里改变反馈节奏，且可以被无 EEG 基线检验。

“EEG 能告诉我什么时候该打扰”不是现成事实。专注程度、愿不愿被打扰、情绪、当前需要何种帮助，是四个不同变量。即使有厂商 Attention 分数，也不能直接把低分等同于“现在应该陪聊”。

## 12 条最有用的证据

### E1｜Muse EEG SDK：能接原始流，但高级 calm 算法不随 SDK 开放【事实】

官方支持 iOS、Android、Windows、macOS，可管理蓝牙、读取数据和记录/回放 .muse 文件。原型许可与商业许可分开。Muse 支持文章明确：SDK 开放传感器与部分处理信号，App 的高级处理指标不直接提供；App 也不支持直接导出原始 EEG。这里的 Muse 是 InteraXon 头环，非 Meta Muse。

对 PRD：不能把官方 App 的 calm 分数当 SDK 必带能力；设备适配与许可申请需要进入依赖表。若采用自己的 band power/代理分数，必须以“相对变化/实验指标”表述。

来源：[Muse Developers](https://choosemuse.com/pages/developers)、[About EEG Data and Muse Biofeedback，2026-10-19](https://choosemuse.my.site.com/s/article/About-EEG-Data-and-Muse-Biofeedback)。已读取。

### E2｜BrainFlow 是设备未知时更合适的“壳”边界【事实＋工程推断】

BrainFlow 提供统一采集/信号处理 API，支持 Muse 与 OpenBCI 等，并含 synthetic、playback、streaming 类型。官方 2026-05-08 发布说明已加入新版 Muse S Athena 协议支持；不要沿用“Athena 一定不支持开源接入”的旧判断。具体头环、固件和 OS 仍要实机验证。

对 PRD：先定义数据契约，采集实现放在可替换 adapter；本机桥接 EEG，再把最少必要的状态摘要送给 Agent。网页/H5 展示由桥接承担，不承诺所有手机浏览器可直接连接 EEG。

来源：[BrainFlow docs](https://brainflow.readthedocs.io/en/stable/index.html)、[5.22.0 release](https://brainflow.org/2026-05-08-muse-anthena/)、[Supported Boards](https://brainflow.readthedocs.io/en/stable/SupportedBoards.html)。已读取；未实测。

### E3｜OpenBCI：开放采集明确，穿戴与电极调试仍是工时【事实】

官方：Ganglion 4 通道/200 Hz，Cyton 8 通道/250 Hz，Cyton+Daisy 16 通道/125 Hz。板卡不等于整套头环，电极通常另购。官方商店当天显示 Ganglion $624.99、Cyton $1,249.00（USD，板卡价；不含所有配件、税费、到华交期）。页面“Sold out”与加购控件并存，不能据此承诺库存。

对 PRD：拿到现成可穿戴且能读数据的设备，比追求通道数更重要。通道多不自动让情绪识别更可靠。

来源：[OpenBCI FAQ，2026-06-29 更新](https://docs.openbci.com/FAQ/HardFAQ/)、[Ganglion 商店](https://shop.openbci.com/products/ganglion-board)、[Cyton 商店](https://shop.openbci.com/products/cyton-biosensing-board-8-channel)。已读取。

### E4｜NeuroSky：Attention 是厂商相对指标，0 可能表示无法可靠计算【事实】

官方 ThinkGear 数据类型包含信号质量、频段功率、Attention/Meditation 和 512 Hz 原始波形。协议说明 Attention/Meditation 常以约 1 Hz 输出；指标 0 不是“零专注”，通常是噪声等原因导致无法可靠计算。闭眼可影响 Meditation，动作、眼动、肌电和接触不良可污染信号。

对 PRD：不能将 0 分触发安抚，不能用闭眼后曲线变化证明情绪被治愈；质量/缺失必须独立于数值。

来源：[数据类型](https://developer.neurosky.com/docs/doku.php?id=mindset_data_types)、[ThinkGear 协议](https://developer.neurosky.com/docs/doku.php?id=thinkgear_communications_protocol)。已读取。具体头环固件兼容性未知。

### E5｜EMOTIV：流与离线能力受型号及许可约束【事实】

Cortex 可订阅原始 EEG、信号质量、频段、性能指标等；EEG 常见 128/256 Hz，具体取决于设备设置。原始流需相应许可 scope；高频性能指标与低频基础指标不同。首次认证需要联网，后续可按许可规定离线，仍有软/硬期限。

对 PRD：不能假定买硬件就有全部实时数据，也不能把“支持离线”写成永久无账号运行。采购前必须确认目标设备＋账户的实际 scope。

来源：[Cortex Getting Started](https://emotiv.gitbook.io/cortex-api)、[Data Subscription](https://emotiv.gitbook.io/cortex-api/data-subscription)、[Offline Support](https://emotiv.gitbook.io/cortex-api/overview-of-api-flow/offline-support)。已读取；价格/当地许可成本未核实，不填数字。

### E6｜BrainCo：确有开发体系，但 EEG 接口不能默认公开可用【事实】

已读取其经 GitHub 域名验证的官方组织：Crimson、Clear、OxyZen 等 BCI SDK 标为私有，需要申请访问；开发文档入口要求登录。公开的机器人手 SDK 不能当作头环 EEG SDK。FocusCalm 官方说明其 App 在设备本地处理 raw EEG/IMU，原始数据会在每次使用结束清除，仅上传部分计算分数；此声明不等于我们已经能获取原始流。

对 PRD：BrainCo 只能写“获得目标型号 SDK 和许可后适配”。采样率、第三方平台、实时 raw/score、商业许可当前均未知。

来源：[BrainCo 官方 GitHub](https://github.com/BrainCoTech)、[开发入口](https://developers.brainco.tech/login/?redirect=%2Fdocs%2Fcrimson-sdk%2F)、[FocusCalm FAQ](https://focuscalm.com/pages/support)。已读取；受限内容未绕过。

### E7｜NeuroSkill：值得借鉴的开源 EEG→Agent 管线，不是已验证的“心理真值”【事实】

原始预印本于 2026-03-03 提交，GPLv3 软件，skills 文档另有许可。官网称本地分析并通过 WebSocket/CLI 输出；当前实时处理以 4 通道为主。官网自己限定 focus/relaxation 等为结合任务、自述代理的组合指标，非已验证生物标志物；73 分不能解释成 73% 专注。可复用思路：本地采集、事件标签、可查询历史、Agent 请求；不能照搬其宣传标题作为本项目已实现科学能力。

来源：[arXiv 2603.03212](https://arxiv.org/abs/2603.03212)、[官方 paper/limitations](https://neuroskill.com/paper)、[官方 GitHub](https://github.com/NeuroSkill-com)。已读取；未运行代码，也未独立复现其效果。

### E8｜NeuroSkill 隐私声明存在内部冲突，需要实际验收【事实】

paper 页面称 WebSocket 仅绑定 127.0.0.1；API 页面却写 0.0.0.0、无认证、可被局域网访问。由此不能宣称“开源本地方案天然不会暴露脑电”。选定版本后应实际检查监听地址，回环绑定、短期配对认证、来源校验、禁止 raw 直接给公网模型、断开后销毁订阅。

来源：[paper privacy](https://neuroskill.com/paper)、[WebSocket API](https://neuroskill.com/api)。同日两页已读取；哪一个对应实际运行默认值尚未知。

### E9｜情绪分类的跨场景泛化不是一个已解决小问题【原始研究事实】

EmoEEG-MC（Scientific Data，2025）记录 60 位青年受试者的 64 通道 EEG，比较视频诱发和想象诱发情绪。作者报告：以 DE 特征做同被试分类，换到另一情绪诱发场景，二分类准确率从 66.7% 降至 57.6%，七分类从 28.9% 降至 20.8%。这是该实验设置的基线结果，不是所有模型的能力上限，也不能外推成消费级头环性能。

对 PRD：以低通道头环判断“你正因离职难过”缺乏依据。可让用户自述提供语义，EEG 只提供经质量控制的变化线索，保留纠错与弃权。

来源：[PMC 原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12229444/)，DOI 10.1038/s41597-025-05349-2。已读取全文；Nature 主站重定向失败后改用合法开放全文。

### E10｜实时 Attention 系统有研究先例，仍应审视标签与验证方式【原始预印本事实】

NeuroPilot（2025）用 FocusCalm 研究在线学习专注，样本 20 人，每人约 20 分钟采集。它证明这是有研究路径的方向，不证明任意头环可以开箱识别所有用户的任意学习状态。样本切片很多也不等于独立受试者很多；随机分窗时尤其应防止同一人的相邻窗口泄漏。

来源：[NeuroPilot arXiv 2510.20958](https://arxiv.org/abs/2510.20958)。已读取摘要；更细模型/准确率不纳入决策结论。

### E11｜一次曲线上升，不足以证明神经反馈产生专属效果【原始研究事实】

预注册、双盲、真实/假反馈与被动对照研究《The nature of alpha modulation through neurofeedback》（2025 预印本）发现，该单次实验中的 alpha 上升并不依赖反馈真实性。不能据此否定所有神经反馈，也不能把我们的 3 分钟体验讲成治疗、长期改善或因果证据。

来源：[arXiv 2509.10046](https://arxiv.org/abs/2509.10046)。已读取摘要，未宣称已同行评审。

### E12｜Muse 已有 AI Coach；当前售价只是采购参考【事实＋未知】

Muse S Athena 官方产品页已展示 Enso the AI Brain Coach（Premium）：解释数据、给个性化计划。因此“EEG＋AI建议”已有竞品，不是空白。美国官方商店当日页面：Muse 2 $249.99，Muse S Athena $474.99（USD）。不含已确认的中国交期、运税与开发许可成本。厂商网站支持的高级反馈不等于 SDK 能力。不要建议团队在未确认到货与实时流前下单；也不应为了 BCI 标签临时自研采集电路。

来源：[Muse 2](https://choosemuse.com/products/muse-2)、[Muse S Athena](https://choosemuse.com/products/muse-s-athena)。已读取，时点快照。

## PRD 应采用的能力契约【设计建议，均非已实现】

```
SensorFrame {
  device_id, model, firmware, source_mode: live|recorded|synthetic,
  device_ts, received_ts, seq, sample_rate_hz, channels,
  contact_quality?, artifact_flag?, raw_available,
  features: [{name, value, unit, algorithm_version}],
  calibration_id?, quality: good|uncertain|poor|missing
}
DerivedState {
  baseline_relative_change?, evidence_window_s,
  confidence: calibrated|uncalibrated|unknown,
  consent_scope, user_label?, expires_at
}
```

不要给“confidence”任意填 0.92；没有校准时写 unknown。raw/score-only 接入分两档，不能把 score-only 包装成独立算法。特征有单位、算法有版本、标签有来源，方能解释“为什么刚才变了”。

设备→本机采集桥→质量门→个人基线→有限反馈控制器→桌面终端/电子吧唧；Agent 只接会话摘要、用户确认与决策日志。大模型不在 4 Hz 声光控制环中，避免延迟/费用/不稳定。把低层连续控制与高层对话/工具调用分开。

### 四档接入状态

| 档位 | 可验证能力 | PRD 可承诺什么 | 不能宣称什么 |
|---|---|---|---|
| A | raw＋质量＋时间戳 | 自有滤波/特征＋可审计实时反馈 | 自动等同情绪或精神诊断 |
| B | 厂商相对指标＋质量 | 基于厂商指标的个体反馈实验 | 自研脑状态识别、百分比专注 |
| C | 指标有但无质量/时间戳 | 数据显示与交互探索，主要由用户显式控制 | 自动闭环已可靠 |
| D | 无实时接入 | 硬件交互/回放研究；明确 EEG 未接通 | 实时 BCI 成果 |

无论哪档，用户说“不想继续”、摘下头环、断流、质量差，都应立即暂停状态推断；不能把旧分数延用成实时状态。恢复后重新检查质量和基线。采集失败可用明确标注的录制回放讲架构，但不能计入实时接入验收。

## 保留 BCI 核心的三个候选，按本任务适配度排序【产品判断】

### A. “一起缓一会儿”：恢复状态的桌面伙伴（推荐进入主 PRD 候选）

目标是需要从忙乱/消耗切回下一件事的成年人；行为频率可能每日，但尚无用户频率证据。用户按实体键开始，选择“安静陪伴/呼吸节奏/准备回到任务”。EEG 提供当下相对变化、接触质量与可视化；桌面宠物/灯/小屏呈现稳定的呼吸和环境反馈。结束时先问感受，再问是否保存本次偏好或生成下一步卡。

亮点：真正的双向硬件闭环；用户自述与信号可以不一致，系统接受纠正；无需全天佩戴；可形成 3–8 分钟仪式。个人化来自逐次选择和确认，不靠将某个频段命名为悲伤。不要让宠物因用户“专注分低”掉血、责备或死亡，避免把情绪支持变成表现压力。

### B. “回到这一页”：任务续接与可控间歇

用户在开始任务时主动提供下一步/当前页面并同意会话。实体终端负责挂起、暂停、恢复；EEG 在有效质量下调整环境反馈和提醒建议，是否切换仍让用户决定。结束恢复时唤回上一张行动卡。比单纯番茄钟多的是理解上下文与能解释的感知，但必须做无 EEG 对照，否则脑机只是昂贵计时器。

### C. 真实宠物照护＋主人 EEG（不建议作为首个 BCI 主闭环）

宠物照护本身有任务与交接价值，但主人的 EEG 对宠物喂食、疫苗、异常行为判断的增益缺少直接因果关系。宠物摄像头/项圈是另一条硬件路线，未解决本次保留人类 BCI 的诉求。可采用“虚拟陪伴宠物”作为 A 的表达界面，但要与真实宠物管理明确区分。

## 三分钟强 Demo【建议脚本，不是实验结果】

1. 0:00–0:25：展示真实头环、实体终端、连接/电极质量、LIVE 标签与正在变化的时间戳。评委按实体键开启；用户选择“想缓一缓，先别聊天”。
2. 0:25–1:05：展示个人基线和实验性相对变化，让终端在有效窗口内改变声光/宠物呼吸。说明它反映信号，不能判断心里在想谁。校准时间若实际超过 40 秒，不裁成假实时；赛前已校准须明确写入状态。
3. 1:05–1:35：故意轻微移动/松开一个接触点，界面显示质量下降并冻结推断，终端保持柔和固定节奏。亮点是“知道自己不知道”，不能把肌电展示为情绪波峰。
4. 1:35–2:10：用户说“其实我没有难过，只是有点累”，系统保留用户确认，撤销先前待确认推测；用户按“先别问”，进入明确冷却。
5. 2:10–2:40：恢复后，用户主动说“帮我接着做刚才那件事”，唤回已授权的任务卡，先预览再确认保存到待办/日历。这里如果没接外部服务就标为本地动作，不把模拟回执说成实际发送。
6. 2:40–3:00：给出真实测试的分母、质量覆盖率、拒绝/断流测试结果，以及 EEG 与无 EEG 的对照情况。没有统计显著差异就说探索性结果，不用 3 分钟体验声称留存增长或疗效。

如果“拒绝/纠错＋任务动作”挤压了 BCI 展示，可把任务卡缩为结束时一个动作，避免又变成聊天产品。

## 黑客松期间可执行的小样本验证【实验设计建议】

先验收工程，再谈 EEG 增益。所有阈值是拟定门槛，不是当前达标结果。

### 工程门槛

- 5 次独立连接尝试记录成功次数、耗时、失败原因；不只展示最好一次。
- 连续 10 分钟记录有效数据比例、断流数、最长间隙；分别统计蓝牙到桥和桥到终端延迟。
- 传感器时间戳到展示的延迟，不与 5–10 秒特征窗口混淆；反馈系统保留平滑与滞回，避免宠物/灯每个采样点乱跳。
- 至少 10 个故障/权限例：接触差、摘下、平移、缺包、时间漂移、蓝牙断开、重连、冷却、撤销授权、回放标签，全部有预期行为与日志。
- 原始 EEG 默认不上传；实际抓包/监听验收；设备数据与任务内容分开保留，结束后删除/导出可验证。

### A/B/C 对照（6–10 位成年人，仅探索性）

- A：同一虚拟宠物＋用户自选节奏/固定声光；不使用 EEG。
- B：相同内容与总时长，加入有效质量＋个人基线的实时 EEG 相对反馈。
- 可选 C：同设备佩戴、反馈回放，显式事先告知此条件可能不取实时数据；只用于对照体验，路演必须标 RECORDED，不以骗过评委为目标。
- 使用交叉顺序/ABBA 或平衡 A/B 顺序，同一任务难度/休息时长；不要所有人先 A 后 B。
- 主指标：愿意再次使用（选择和原因）、感到被打扰/被评价的评分、完成会话率；任务型方案另测恢复到第一步耗时/漏项。记录设备不舒适、佩戴/连接/校准成本。
- EEG 本身的有效覆盖率、相对变化可重复性单列；不能用“alpha 上升”替代用户受益。主观“更舒服”也不能单独证明脑机的特定因果效果。
- 汇报每人配对结果、均值或中位数、离散度、样本量与失败样本；不拿几十万个滑窗当几十万位用户，不宣称主流用户留存/疗效。

### 若要测试“何时打扰”

将模型离线推荐与用户标签比较，先采用影子模式而非频繁真实打断。对照必须有“日历/手动勿扰/当前交互＋用户偏好”的无 EEG 模型；加 EEG 后比较误打扰、漏掉希望帮助的时刻、可用数据覆盖率。跨用户或跨日测试分开，整段 session 划分，禁用相邻窗口混入 train/test。EEG 不得越过拒绝、静默期和权限的硬规则。

## 尚未解决、主 PRD 必须标注的依赖

1. 具体头环、固件、SDK 许可和实际可读数据；硬件到手日不确定，不能给出无条件日程承诺。
2. 团队能否在现场完成稳定蓝牙、信号质量检测、实体终端声光反馈；不能把漂亮的 EEG 曲线当完成。
3. 采样窗口/特征算法/校准是否可用，任何 focus/relaxation 名称都需来源和限制；未知设备不能先承诺自研情绪识别。
4. 是否存在真实用户认为 EEG 比“手动说我累了”更值得佩戴；这是最关键的产品假设，也可能否定某种具体交互，但不等于放弃硬件研究。
5. 比赛代码/素材现场产出与第三方依赖披露规则由主研究统一确认；本文件只形成研究、能力契约和验收设计，不预建参赛实现。
