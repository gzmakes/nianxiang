## 3. 怎样判断完整、正确、合理

完整性按当前可见对话＋可读取原始资料界定，不保证未展示历史从未压缩。coverage-matrix.json逐项记录用户点、参考来源、处理状态和阅读位置。后置、待验证与不采纳也说明理由，不用“全都做了”冒充完整。

正确性分层：用户决定以用户原话为准；队长构想、会议与Claude报告是参考；厂商资料只支持公开能力声明；论文结论受样本/读取深度限制；转化、商业化和BCI增益仍是推断。claim-audit.json记录14项高影响断言，本轮未重新全文核验全部141条旧记录。

合理性按一个具体用户事件、替代成本、硬件独立贡献、BCI增量、现场有效工时和数据处理限制审查。24项需求不都要并行完成；条件P0随Case生效，五工作包用于现场裁剪。
