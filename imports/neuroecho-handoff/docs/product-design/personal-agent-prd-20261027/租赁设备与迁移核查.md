## 结论

**这套设备的采集规格足以支撑 4 秒频谱特征＋梯度提升推理的工程链，但“能稳定拿到带时间戳、单位与导联信息的实时原始流”尚未得到材料证明。** 真正的优先级是原始流与数据契约，不是把采样率开到 32 kHz、把通道开到 64。

这是上海全澜/澜鲸医疗的研究型电生理采集平台，系列包含记录刺激一体及纯记录配置。Brain Bookmark 本次只使用采集；电刺激能力不进入功能和演示链。它可以帮助验证真实闭环，但并不把“闭眼/心算分类器”自动升级成日常分心识别器。

## Brain Bookmark 已有链与需要避免的迁移误解

### 当前可确认的起点

已交叉核对网站源码与公开README。公开版位于 [Brain Bookmark](https://dililianxice.github.io/brain-bookmark/)，对应 GitHub Pages 目录。README 说明：这是预计算真实 EEG 回放＋本页编辑内容书签，不在访问者浏览器做实时 EEG 推理；没有 Python 后端，也没有云端 LLM。

当前 README 写：名义 512Hz、1–40Hz 四阶因果带通、4s窗/2s步长、Welch 频谱 13项特征、Gradient Boosting 三任务分类、3次得分平均＋连续3次规则＋最高得分至少0.5＋15s冷却。59.5%是页面作者自报的测试平衡准确率，不是我们复现结果，更不是分心识别率。模型细节另见配套源码核查；本轮未获取冻结模型权重、完整训练/划分 manifest，不对训练复现作完成声明。

原始数据集的一手元数据已亲自读取：[Mendeley Data, DOI 10.17632/gy4sbnn389.1](https://data.mendeley.com/datasets/gy4sbnn389/1)，2025-07-04，v1，50位参与者、NeuroSky MindWave、Fp1单通道，每任务约60秒，闭眼放松/中等心算/困难心算，CC BY4.0。数据页没有交代足够的参考电极/增益换算/抗混叠/时钟细节；512Hz来自项目 README 的名义设定，而不是把 PDF 的32kHz当成匹配。

### 可以较直接保留的部分【工程判断】

- 任务书签的保存/恢复、用户确认与撤销、冷却与拒绝策略、事件日志、UI和Agent接口。实时 raw、回放和模拟数据共用事件接口，但 `source_mode` 不能丢。
- 4s尾随窗口、频谱特征提取和树模型推理的架构；计算负担相对小。RSC 最高采样/多通道能力远超该分类链最低输入需求，不需要满配运行。
- 质量差就弃权、无新样本就不触发、记录原始事件时间与模型输出时间。

### 不能直接迁移的部分【工程推断，待验证】

1. **采样率和数据帧：** RSC 不一定有512Hz档。若不是512Hz，需要抗混叠低通后重采样，并把事件时间/序号一起映射；不能简单每 N 点抽1点，尤其32kHz到512Hz不是整数比。MNE文档也提醒降采样可能使触发时间抖动，marker应从原始流记录并同步转换。[MNE Raw.resample](https://mne.tools/stable/generated/mne.io.Raw.html#mne.io.Raw.resample)。
2. **导联与参考：** 多通道帽中应明确选取真实 Fp1及实际参考/地；不能“第1通道就当Fp1”。参考从耳部/单参考换成平均参考，频谱就会变；采集更多通道不能直接把13维单通道输入变成13×64维后丢给原树模型。
3. **幅值单位和增益：** 训练 raw 可能是设备计数，RSC API可能给µV。13特征中的绝对功率、RMS、方差及其对数有尺度敏感性；相对功率/比值较能抵抗整体幅值缩放，但不是所有跨设备影响都抵消。没有原训练换算约定，不能仅调一个阈值便宣称兼容。
4. **前端与滤波状态：** 电极接触、模拟滤波、数字滤波、notch、量程、参考和噪声均不同。当前公开方案每4s窗的因果滤波若重置，会有边缘瞬态；在线连续滤波保留状态虽然通常更自然，却改变训练特征分布。必须复刻再对照，或统一重训；不能默默把双向零相位处理搬进实时链。
5. **训练标签与目标：** 三类是任务条件，不是专注/走神/情绪三个心理真值。闭眼放松与睁眼心算之间可能主要体现闭眼和任务刺激差异；不可以把类别翻译成“你分心了”。连续困难心算回放中的类别翻转也可能是误差或漂移。
6. **人群与场景：** 原数据集短任务、原设备与受控场景；黑客松现场说话、转头、笑、键盘输入、展厅电噪声都是新的分布。移植到新设备新用户需整人/整日/整任务留出验证，不能随机拆相邻重叠窗口。
7. **概率与触发节奏：** 树模型得分不自动是校准置信度；跨设备0.5阈值更不能保证可靠。4s窗与2s步长加平滑/连续门控会产生数秒以上响应时间；不能宣传“毫秒级分心识别”。4s是历史覆盖长度，不等于每次决策只有4s延迟。
8. **模型与运行物：** 前端回放的demo-data.json不是模型文件。必须取得/重新训练并导出冻结模型、特征顺序、滤波参数、版本与校准；目前公开README不能让别人在现场独立复现59.5%。

## 建议实时链：先通采集，再迁模型

```
RSC记录模式 → 专用路由器 → 厂商raw SDK/支持的实时输出
 → 本机adapter {seq, device_ts, sample_rate, units, channel_map, impedance/quality}
 → 原始流记录＋marker轨迹
 → 可审计的抗混叠/参考/重采样/滤波/伪迹质量门
 → 最近4s窗口（初始2s步长）→冻结13特征契约→模型得分＋弃权
 → 平滑/连续门控/冷却/用户拒绝规则
 → 书签候选 →本地保存/用户确认→任务恢复
```

- 如果厂商只有录完导出：可以完成录制→离线处理，但不叫实时接入；先争取官方支持的raw订阅/文件tail/LSL等途径，不能默认存在LSL或BrainFlow驱动。
- 如果只有GUI波形：不能把屏幕截图/OCR当合格raw传输方案。
- LLM在需要组织续做提示时使用任务摘要；不接满速64通道原始波形，不控制电刺激。
- 建议先用设备支持的较低采样率和少量明确导联；先复现Fp1链，同时记录其余有价值导联供后续研究。能选多少/是否降采样受许可/固件影响，待交付确认。
- 数据量不是主要算法收益：按64通道×32,000Hz×24bit估算，未封包原始净荷约49.15Mbps，float32约65.54Mbps；实际网络开销更高。该数为算术估计，不是设备实测。不能为了宣传最高参数让展厅Wi-Fi成为瓶颈。

### 现场到货后必须跑通（建议验收门槛，非当前结果）

1. **官方链与自有链同时对照：** 在同一时段，厂商软件和我们的adapter读到波形、通道/单位/样本数一致；若不允许同时访问，用同段记录核对导出与订阅的换算。
2. **连续稳定性：** 至少20分钟记录包序号、时间间隙、丢包、最长中断、端到端延迟分布；不能只看一张“连接成功”。链路断开与恢复后必须标记不连续，禁止拼接成无缝4秒窗。
3. **质量门：** 按厂商指导验证接触不良/松动、眨眼/动作污染与断流，系统暂停分类并保留原因；阻抗值合格不等于无眼肌伪迹。
4. **时间/marker：** 以可知的事件或测试信号验证marker与EEG对齐、时钟漂移和trigger编码；没有TTL时可用软件marker但报告实际误差，不承诺ERP级精度。
5. **算法契约：** 用同段raw离线与实时流重放产生同一13维特征和分数（容差预设）；检查因果滤波状态、窗口边界、单位、参考、sample_rate与metadata，禁止“看起来差不多”。
6. **目标验证：** 至少先记录新设备上的三类原任务，按整段session留出检查混淆矩阵、平衡准确率及弃权覆盖率；不达标就将展示定位为相对频谱/用户确认驱动的书签实验，保留真实脑电，但不叫日常分心检测完成。
7. **额外反例：** 眼开安静、眼闭思考、睁眼心算、说话/转头、正常打字；检查模型是否只凭闭眼或肌电触发。触发书签误报比一个分类分数更贴近产品体验。
8. **展厅网络：** 专用路由器、本机局域网，无需公众Wi-Fi；核验SDK离线、数据端口、默认认证和监听范围。PDF没有给加密与访问控制承诺，不能先宣称数据安全已实现。
9. **可恢复交付：** 一份合法可用的原始录制样本、SDK示例、数据字典、日志、许可证说明；演示备用录制标RECORDED，实际LIVE只按真实接通状态显示。

## 租赁对产品决策的影响

正向：能用研究级采集完成真正的硬件闭环，并在日志上解释每次状态与书签的来源；租赁适合验证技术与用户体验，减少先自制采集硬件的工时。

限制：多导联湿帽和路由器/PC链路更接近受控研究或体验站，尚不能证明消费级长期佩戴、成本、上手门槛和日常使用成立。演示叙事可明确为“用研究设备验证闭环，后续才选择轻量传感方案”，而不是把租来的64通道平台画成已量产电子吧唧。

**最值得拿分的演示变化：真实信号可见、信号不好会停、类别不被夸写成心理事实、书签确实保存且能恢复。** 这比展示最高采样率更容易证明工程完整性与产品判断。
