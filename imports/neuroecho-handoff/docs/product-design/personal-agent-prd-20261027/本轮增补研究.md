### Brain Bookmark已有成果的准确边界

[打开队友Brain Bookmark](https://dililianxice.github.io/brain-bookmark/) · [公开源码](https://github.com/Dililianxice/Dililianxice.github.io/tree/main/brain-bookmark)

目前是GitHub Pages静态站：真实历史EEG与预计算得分回放，保存当前网页编辑器内容、光标位置、目标和用户填的下一步到浏览器localStorage，并可导出JSON；没有现场设备、在线模型推理、Python服务、云LLM或跨App上下文。历史信号与访客此刻输入的文字是真实数据，但并非同一人同一时刻的同步记录。

原始数据为NeuroSky Fp1单通道、闭眼休息／中等心算／困难心算；README称名义512Hz，4秒窗、2秒步长、13项频谱与幅值特征、梯度提升分类。59.5%是项目自报的三任务测试平衡准确率，不是我们独立复现结果，更不是分心准确率。公开部分缺训练／split清单与冻结模型文件。原数据页称50人，项目51个原始ID的差异也需解释。[原始数据集](https://data.mendeley.com/datasets/gy4sbnn389/1)

默认片段全程真值是困难心算，20秒处预计算事件为“中等→困难”输出变化。因此它证明事件能触发保存流程，不证明现场某人分心。应保留原类别名；若未来要研究走神，另采独立的真实中断／走神标注，加入眼开安静、眼闭思考、说话与打字等反例。

### 最薄升级路径

RSC记录模式 → 官方实时输出 → 本地RSCAdapter → 数据单位／导联／参考／采样契约 → 质量门与可弃权特征 → 任务条件或待确认状态事件 → 书签候选与拒绝策略 → 当前授权文档快照 → 用户修改下一步 → 展示适配器。

先验通实时raw与质量，不立即搬三分类阈值。RSC与原MindWave的单位、参考、滤波与噪声不同；64通道和更高采样不自动解决域迁移。冻结特征顺序，保留因果处理和会话边界；按整人／整段验证，不随机混分重叠窗口。若原模型迁移不达标，可真实展示相对频谱＋用户确认书签，同时把三任务解码保留为独立回放，不给它改名“实时分心”。

书签首先保存用户明确授权的本页／选定文档，不默认全屏抓取。保存后必须能恢复原文与位置，并验证文档版本冲突；“知道了，继续写”按钮变字不算恢复成功。AI可在有来源片段上建议一个下一步，不能补写不存在的取舍。

## 17 交易者陪伴与自订约定

朋友提出了一个有具体痛点的候选：连续亏损、睡眠不足、行情变化时，一个人消化压力，也可能忘记盘前给自己的约定。朋友愿参与可以成为访谈与试用入口；尚不等于需求、付费或机构采购已验证。本版不写私人姓名、联系方式、地址，也不把群聊夸赞当背书。

**暂名“止一拍”，服务愿意为自己设定流程的成年活跃投资者。** 目标是记得自己的流程、可自愿暂停、复盘一次事件，并保留离开盘面的权利。长期定投者、只想获得荐股或回本指令的人，不自动纳入核心客群。首版不接真实券商账户、个股建议、收益排名或订单控制。

### 研究支持的是探索空间，不是高手鉴定

2026年NBER工作论文研究16名同一A股自营公司的日内交易者，单通道NeuroSky，关联9,544笔成交；同人同小时内，更成功交易前30秒的参与度指数上升更大，背景高指数没有正向预测力。作者承认关联性与混杂，尚非同行评审论文。它不能简化成“脑波越平、越低就是高手”，也不能当作零售投资者情绪或股票未来走势解码器。[论文主页](https://www.nber.org/papers/w35345)

经典Lo／Repin的2002研究主要是皮电与心血管，2005研究主要是情绪自报，不是EEG分类效果。正负情绪、唤醒、专注、风险偏好、交易技能和未来收益要分别定义。研究论文可以支持新颖性与实验设计，不能用论文摘要给产品贴收益承诺。

已有[TradeZella](https://www.tradezella.com/)宣传情绪、风险和习惯Agent；[Tradovate Prop](https://prop.tradovate.com/blogs/manual-lockout-tradovate-prop)已有特定模拟评估账户的手动冷静锁。我们必须比较自报／行为／预承诺基线，证明多一个EEG输入值得佩戴。提醒暂停不等于券商级封单；真实账户控制还可能平仓／撤单，不能为演示随意接入。

### 一条可验收闭环

用户事前写自己的约定，例如“连续两次模拟亏损后，提醒我先看一眼自己的计划”。模拟事件满足条件时，系统依据约定与用户授权轻问一次；EEG只提供质量合格的弱证据，不能据波动断言恐惧、失控或菜鸟。用户选择暂停观察、记录一次感受或不再提醒；Agent按确认整理复盘卡。它不会下单、阻止真实订单、催人回本或用热血名言鼓励加码。

若EEG质量差，停用生理解释；明确约定的事件提醒仍可独立成立。若用户拒绝或处于静默范围，先遵守硬规则。用户说“我很平静，只是兴奋”时按原话记录，不让模型借脑电反驳本人。名人低谷故事只用可核出处，首版优先使用用户自己的盘前约定。

EEG增益需要做同内容、同时长、同终端的有／无真实EEG比较，报告误提醒、流程遗漏、复盘完成与佩戴负担；不以短期盈亏验收。若提示反而增加盯盘与操作冲动，或用户只有在承诺预测收益时才愿付费，应改定位。我们的北极星不是成交次数和在线时长。

### dsh-pet可以作为展示适配器

DeepSeek模型、官方DeepSeek Harness、社区PC2005-cloud/dsh-pet是三层东西。核查原仓与npm版本为0.3.8，源码树有106个WebM，97段是旧描述；数量会变，不拿热度或动画数当产品壁垒。[原仓](https://github.com/PC2005-cloud/dsh-pet)

本机已有HTTP／OpenAPI：取得控制锁、投递外部文本、播放动画、查询playback回执、释放锁；另可写入work-status。用户拖动／隐藏可抢回控制。最薄接法是保留自己的Agent和书签服务，增加PresentationAdapter，把“已保存、待确认、暂停、信号不足”映射成少量角色表现。不把beta或alpha频段直接映射为开心／悲伤。

### 用户视频提供的是另一种表达线索
