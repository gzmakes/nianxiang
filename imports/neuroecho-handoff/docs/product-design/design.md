# 回响 · 设计规范 design.md

版本 v0.1 · 2026-10-29 · 适用：iOS / Android / Web / 桌面客户端
状态：视觉方向已定，细节待团队评审。所有示例文案、数据均为示意。

## 0. 一句话

**一条对话，一块侧面板，一团会呼吸的光。**
浅色、通透、克制。它大部分时间安静，需要出现时再出现。

### 结构来源
- 参考你给的图 2（Today）：左侧一条连续对话，右侧一块可收起的面板。
- 保留这个结构的好处：上下文连续，学习成本低。
- 修掉它的一个问题：东西全堆在一条线上。做法是**同一条时间线上加"话题视图"筛选**（全部 / 周五方案 / 日常），不是拆成多个对话框。

## 1. 设计原则

1. **玻璃是操作层，不是内容层。** 玻璃只用在悬浮的导航、按钮、输入条、滑块旋钮。文字内容放在近乎不透明的白卡里。
2. **只有两种颜色，很淡。** 雾蓝 + 淡杏。别的颜色一律不进主画面。
3. **情绪用光和表情说，不用文案卖萌。** 它的状态靠一团光表达，文案保持平实。
4. **做事前先说清楚。** 任何会动东西的操作，先给"我打算这样做"卡片：读什么、改什么、不碰什么。可撤回。
5. **每条记忆都能被追溯、改、忘。** 记忆条目必须标出处（你的原话 / 你选定的文档 / 推测·待确认）。
6. **推测不当事实。** 推测用虚线标签，必须你点"是的"才记下。
7. **宁可少说。** 默认安静。晚点、今天不提、暂停到明天，永远一步可达。

## 2. 颜色

### 2.1 基础色板
| Token | 值 | 用途 |
|---|---|---|
| `bg-start` | `#F8FAFF` | 背景渐变起点 |
| `bg-mid` | `#EDF1FF` | 背景渐变中段（雾蓝） |
| `bg-end` | `#FFF4EE` | 背景渐变终点（淡杏） |
| `blob-blue` | `#C6D4FF` | 弥散光斑 A（不透明度 .85） |
| `blob-peach` | `#FFD9C6` | 弥散光斑 B（不透明度 .8） |
| `ink` | `#1B2433` | 主文字、主按钮底色 |
| `ink-mute` | `#56627A` | 次要文字 |
| `chip-blue` | `#DCE5FF` | 选中态、序号圆、图标底 |
| `chip-peach` | `#FFE3D3` | 第二强调底色 |
| `user-bubble` | `rgba(190,205,255,.55)` | 用户气泡 |
| `card` | `rgba(255,255,255,.80)` | 内容卡（近乎不透明） |
| `danger` | `#B3261E` | 仅用于"忘掉这条"等破坏性操作 |

### 2.2 规则
- 一屏之内，彩色面积 ≤ 背景光斑 + 小面积 chip。不新增第三种色相。
- 主按钮永远是 `ink` 底白字。次按钮是 `ink` 7% 透明底。
- 对比度：正文 `ink` on `card` ≥ 12:1；次要文字 `ink-mute` on `card` ≥ 4.5:1。上线前用工具复核。
- 暗色模式：本版**未设计**，列入后续。

## 3. 背景：动态渐变

- 底层：`linear-gradient(160deg, bg-start 0%, bg-mid 38%, bg-end 100%)`，`background-size: 200% 200%`，18 秒往复位移。
- 上层：两团模糊光斑（`filter: blur(56px)`），16 秒、20 秒往复漂移，缩放 1.0 → 1.2。
- 动画只动 `transform` 和 `background-position`，**不动 blur 半径**。
- 必须支持 `prefers-reduced-motion`：开启则全部静止。App 内也要有"减少动态"开关。
- 光斑位置避开正文区域下方的大面积文字，保证文字不压在高饱和处。

## 4. 液态玻璃

### 4.1 基础配方（Web / 桌面）
```css
.glass{
  position:relative;
  background:linear-gradient(135deg,rgba(255,255,255,.66),rgba(255,255,255,.2) 48%,rgba(255,255,255,.4));
  -webkit-backdrop-filter:blur(28px) saturate(190%) brightness(1.04);
  backdrop-filter:blur(28px) saturate(190%) brightness(1.04);
  border:1px solid rgba(255,255,255,.72);
  box-shadow:
    inset 0 1.5px 0 rgba(255,255,255,.98),   /* 顶部亮边 */
    inset 1px 0 0 rgba(255,255,255,.55),
    inset 0 -1px 0 rgba(110,130,200,.2),      /* 底部冷色暗边 */
    0 12px 32px rgba(80,100,170,.2),
    0 2px 6px rgba(80,100,170,.1);
}
.glass::after{ /* 左上高光 */
  content:"";position:absolute;inset:0;border-radius:inherit;z-index:-1;pointer-events:none;
  background:radial-gradient(120% 90% at 18% 0%,rgba(255,255,255,.6),rgba(255,255,255,0) 55%);
}
@supports not ((backdrop-filter:blur(1px)) or (-webkit-backdrop-filter:blur(1px))){.glass{background:rgba(255,255,255,.92)}}
@media (prefers-reduced-transparency:reduce){.glass{background:rgba(255,255,255,.94)}}
```

### 4.2 使用规则
- **下面必须压着内容。** 玻璃下面只有空背景时，磨砂看不出来。设计稿里底部浮层下方都放了卡片。
- 一屏最多 3–4 组玻璃。超过就不是"点缀"了。
- **不用玻璃的地方：** 正文气泡、记忆卡、计划卡、列表行。
- 玻璃上的文字用 `ink`，字重 ≥ 500。
- 不要给玻璃叠玻璃（玻璃按钮放在玻璃条里面时，按钮改用白色实底）。
- 选中态用白色实底小胶囊（`rgba(255,255,255,.88)` + 轻阴影），不用彩色。

### 4.3 各端实现建议
| 端 | 做法 | 备注 |
|---|---|---|
| iOS | iOS 26 起优先用系统 Liquid Glass（SwiftUI `glassEffect`）；更低版本回退到 `UIBlurEffect` / `Material` | 系统 API 的具体名称与可用版本，开发前以 Apple 官方文档为准 |
| Android | 12+ 可用 `RenderEffect` 做模糊；低版本、低端机回退为 `rgba(255,255,255,.92)` 实色 | 真·背景模糊在 Android 上要自己处理，需评估性能；社区有第三方库可选，选型待验证 |
| Web | 4.1 的 CSS | Safari 要带 `-webkit-` 前缀；Firefox 之外多数现代浏览器支持，仍需实测 |
| 桌面（Mac） | 窗口用系统 vibrancy / 原生材质；菜单栏弹层、唤起条用系统材质 | Electron 有 `vibrancy` 窗口选项；Tauri 有窗口特效插件。框架待定 |

## 6. 形状、间距、触控

- 圆角：卡片 22–26，对话气泡 22（靠发送方的一角 6），按钮胶囊 = 高度 / 2，面板 24–28，手机外框 44（iOS）/ 36（Android）。
- 间距基数 4：4 / 8 / 12 / 16 / 20 / 24。页面左右边距：手机 16–20，桌面 24–40。
- **触控目标 ≥ 44×44（iOS / Web / 桌面），≥ 48×48（Android）。** 小于这个尺寸的图标按钮，热区要外扩。
- 玻璃浮层距屏幕边：手机 16–24，底部 22（iOS 导航条）。

## 7. 核心组件

### 7.1 它的光（品牌核心元素）
一颗通透的玻璃球，有高光和亮边。用颜色、大小、亮度表达状态。

| 状态 | 视觉 | 含义 |
|---|---|---|
| 安静陪着 | 雾蓝，缓慢呼吸 | 默认，没在做事 |
| 在听你说 | 淡杏，更大更近 | 你在输入 / 语音 |
| 想起一件事 | 蓝杏交融，亮一下 | 有一件事要先问你 |
| 先不打扰 | 变小变淡 | 你要求别提醒，或判断你很忙 |

- 尺寸：头像 30–48，卡片 56–60，首页主视觉 250。
- 用户可调"光的强度"、可开"减少动态"。

### 7.2 对话
- 用户气泡：雾蓝半透明，靠右。
- 它的气泡：白卡，靠左。
- 一条主时间线。时间分隔用 `今天 · 下午` 小字。
- 话题视图（Web / 桌面顶部）：`全部 / 周五方案 / 日常`，只是筛选。

### 7.3 计划卡（"我打算这样做"）—— 做事前必出现
结构固定：
1. 标题："我打算这样做"
2. 2–4 条步骤（读什么 / 做什么 / 不碰什么），用编号圆点
3. 按钮：`好，开始`（主）· `改一下`（次）· `不用`（文字）
4. 底部两个小入口：`为什么先问你` · `开始后可撤回`

规则：涉及写入、发送、外部连接的操作，一律先出计划卡。纯读取也要说明范围。

### 7.4 记忆条目
- 标题一句话 + 一行"我会怎么用" + 来源标签。
- 来源标签三种：`你的原话`、`来自你选定的文档`、`推测 · 待你确认`（虚线框）。
- 推测条目带 `是的 / 不是` 两个按钮，没点"是的"不生效。
- 详情页必须有：说于 / 记下于 / 用在 三行；下次用到它时它会怎么说的预览；`改一改这条` / `忘掉这条`（红）。
- 忘掉一条，由它得出的内容一并清除，要写明。

### 7.5 提醒（克制）
- 一次只提一件事。给三个出口：`现在看` / `晚点` / `今天不提`。
- "它没有提醒你的事"要有一个数字入口，让人知道它忍住了什么。
- 通知不带声音；桌面通知用同样的三个出口。

### 7.6 权限与连接
- 默认全部关闭。逐项开启，只读优先。
- 每一项写清范围："只读 · 你选定的 3 个文件"。
- 有"它刚刚用过"记录。
- 随时一键收回。

## 8. 各端规格

### 8.1 iOS（390×844 基准）
- 状态栏 + 顶部玻璃组：搜索按钮 · 头像状态胶囊（光 + "回响" + 状态）· 设置按钮。
- 对话屏：全屏对话流，输入条（玻璃，高 56）悬浮在导航上方，导航条（玻璃，高 64，圆角 32）悬浮在底部。
- 底部三项：`回响`（今天）· `对话` · `记忆`。连接放在设置里。
- "今天"屏：大标题 30，玻璃分段控件 `今天 / 记忆 / 连接`，下方白卡堆叠。
- 手势：左边缘右滑返回；长按消息出 `复制 / 为什么这样说 / 记下这句`。
- 触感：计划卡点"好，开始"用轻触感；撤回成功用成功触感。
- 适配：Dynamic Type 要支持到至少 +2 档，气泡和卡片随之增高，不截断。

### 8.2 Android（412×892 基准）
- 遵循 Material 3 的结构：顶部应用栏（头像 + 标题 + 状态 + 搜索 + 更多），底部导航栏（图标 + 标签 + 胶囊指示器 64×32）。
- 与 iOS 的区别：
  - 输入条用白色实底胶囊（不做玻璃），保证低端机流畅。
  - 导航栏做玻璃，不支持时回退为实色。
  - 按钮高 40，触控热区 48；计划卡按钮靠右排列，主按钮在最右。
  - "今天"屏用主要标签页（下划线指示），设置项用 M3 开关。
- 返回：系统手势返回。底部留 24 的手势条空间。
- 通知：使用系统通知渠道，分"一件事"和"静默汇总"两类；默认静默。
- 适配：支持字体缩放到 200%、深浅色跟随系统（暗色待设计）。

### 8.3 Web（1400×860 窗口基准）
- 三栏：左侧玻璃导航栏（72）· 中间对话（自适应，内容最大宽 700）· 右侧"今天"面板（392，可收起）。
- 顶部玻璃胶囊：光 + 名称 + 话题筛选 + 搜索。
- 输入条居中，宽 700，悬浮在底部。
- 响应式：
  - ≥ 1200：三栏。
  - 900–1199：右侧面板变为抽屉，用面板按钮唤出。
  - < 900：切换为手机布局（顶部玻璃组 + 底部导航）。
- 键盘：`Enter` 发送，`Shift+Enter` 换行，`⌘/Ctrl+K` 搜索，`Esc` 关抽屉。焦点样式必须可见（2px `ink` 外描边）。
- 浏览器内的权限范围只含网页可授权的内容；本地文件夹授权在桌面客户端里做。

### 8.4 桌面客户端（macOS 基准，1000×830 窗口）
- 结构对齐图 2：左侧对话，右侧圆角面板，窗口无传统标题栏，红黄绿按钮嵌入左上。
- 右侧面板默认展示"它能看的"：本机文件夹、日历等的只读开关，默认关闭；可切到 `连接 / 记忆`。
- 系统整合（桌面独有）：
  1. **菜单栏图标**：显示光的状态。点开是弹层：当前状态、一件事、`暂停到明天`、设置。
  2. **全局唤起条**：快捷键（默认 `⌥ Space`），玻璃输入条 + 三个快捷动作（接着做 / 看今天 / 记一件事）。
  3. **系统通知**：同样的 `现在看 / 晚点` 两个出口，不带声音。
- Windows 版本：本稿未单独设计。后续沿用同一结构，材质换为 Mica / Acrylic，菜单栏弹层对应系统托盘弹层。

## 9. 交互模式

| 场景 | 做法 |
|---|---|
| 它想做事 | 先出计划卡，等你点 |
| 做完 | 给结果 + `撤回`，撤回入口至少保留到下次打开 |
| 它不确定 | 问一句，不猜；问题里写明为什么问 |
| 它想记点什么 | 出"它想记住一件小事"卡：`记下 / 不对，改一下`，并写"不记也可以，什么都不会改变" |
| 用户说"别提这个" | 立即生效，并在记忆里出现一条可见的规则 |
| 没有该做的事 | 保持安静，不制造存在感 |
| 出错 | 说清发生了什么、有没有改东西、怎么回到之前 |

## 10. 文案语气

- 平实、短句、不撒娇、不说教。
- 先说事实，再给选择。
- 示例：
  - "接得上。你停在第 3 段。"
  - "都不急，放到明天早上也行。"
  - "不记也可以，什么都不会改变。"
- 避免：`亲亲`、`宝子`、连续感叹号、"我是你的 AI 小助手"、替用户下情绪判断（例如"你一定很难过"）。
- **人格最终定调（朋友 / 树洞 / 助理）由团队决定**，文案要在定调后统一过一遍。

---

## 11. 可访问性

- 所有图标按钮有文本标签（`aria-label` / 无障碍标签）。
- 光球图形有文字描述（"安静陪着：淡蓝的光，缓慢呼吸"）。
- 不只靠颜色传达状态：状态同时有文字。
- 支持：减少动态、降低透明度、动态字体、屏幕阅读器、键盘全程可操作（Web / 桌面）。
- 玻璃在"降低透明度"下回退为 `rgba(255,255,255,.94)`。

---

## 12. 不做的事

- 不加第三种主色。
- 不在正文、记忆卡、列表行上用玻璃。
- 不用会闪烁或高频脉冲的动画。
- 不用拟人化的卖萌表情包替代状态光。
- 不用彩色渐变按钮。
- 不把推测写成"你喜欢……"这类事实语气。
- 不使用任何现成角色、商标或他人素材的形象。吉祥物若要做，用原创设计。

---

## 13. 已知缺口

- 暗色模式、平板布局、Windows / Linux 客户端、手表端：未设计。
- 语音交互与脑电（EEG）相关界面：未设计。如果做，实时 / 回放 / 合成数据必须有常驻标记，信号不足时界面要主动说"现在不判断"。
- "它的光"的真实动效：画布里是静态示意，需要在可交互原型里验证节奏。
- 低端 Android 机上的玻璃性能：待实测。
- 对比度、字号、触控热区：需要在真实设备上走查。
