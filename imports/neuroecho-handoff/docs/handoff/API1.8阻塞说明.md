## 启动和限制

主源码不打包模型 key、账户登录、私人数据库、依赖虚拟环境、第三方个人表情图库或 SDK。队友需要安装依赖、配置自己的模型和已有授权；本机 `dsh-meme` 图库仅在对应机器自行准备。当前用户已选择暂不新增账号授权；飞书等来源实际授权与读取仍须逐项确认。

本轮后端合成回归 869 项及 40 子测试通过（版本号更新前），另 2 项因环境不允许监听端口未运行；版本更新后相关 135 项通过。Web/桌面 Node 脚本 663 项通过。最终解压出来的主源码又通过 62 项后端及 26 项前端关键检查。iOS 宿主与 Android JVM/语法验证不代表手机 SDK 构建和真机验收。

真实模型与外部来源、本候选浏览器、手机配对、原生安装、Windows 运行、音频扬声器和设备仍需单独验证；脑机当前只有专注度而非情绪解码，Rokid 留待真机联调。正在运行的服务未重启，没有应用本候选。另一条并行任务仍在扩展桌面接入，后续成果未包含在此快照，应之后再做语义合并和回归。

历史截图、录屏、桌面工件及第三方逆向材料可能包含个人信息或受权利限制。分享前请审阅 `02`、`03`；文件排除规则和校验和不等于全面安全审查或授权分发。`文件清单.json` 记录普通文件 SHA-256 和符号链接目标，可用于核对拷贝，不能证明运行成功。
