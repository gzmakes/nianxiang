# 心情功能：心理学调研与实验设计

日期：2026-10-30。目的：帮助用户表达和回顾自己的感受，而不是诊断、评分或替用户判断。

## 录屏和理论：有哪些对应，哪些不能直接等同

录屏是一张连续的二维平面：左到右从“不愉悦”到“愉悦”，下到上从低到高能量；拖动点时颜色和情绪词变化，最后由本人确认。**从界面形式看，它与 Russell 的情绪环形模型相近；仅凭录屏无法确认作者具体采用哪一套词库或规则。** Russell 1980 年论文研究愉悦度和唤醒度两个维度，并考察了 28 个情绪相关词，不是声称人只有固定的 16 种情绪。[Russell 原论文](https://pdodds.w3.uvm.edu/research/papers/others/1980/russell1980a.pdf)

Russell 等的 [Affect Grid 原论文](https://www.researchgate.net/profile/G-Mendelsohn/publication/232501584_Affect_Grid_A_Single-Item_Scale_of_Pleasure_and_Arousal/links/55bfe22f08aed621de13a34a/Affect-Grid-A-Single-Item-Scale-of-Pleasure-and-Arousal.pdf) 进一步用二维网格记录当下感受；其研究不是对这里的中文界面或全天汇总的验证。

“情绪轮”是另一类表达方式，也存在不同版本，不能自动与此二维图或固定的 16 个标签画等号。目前没有足够证据确认用户指的具体“16 情绪”版本；应该以用户选择、语言习惯和后续试用体验确定词汇，而不是把某套数量宣称为心理学标准。

跨语言研究观察到情绪词语既有文化差异，也存在愉悦与激活的共同结构；这支持为用户保留自己的表达方式，但不证明中文用户对每个词的理解相同。[Jackson 等，Science 2019](https://openresearch-repository.anu.edu.au/items/3bf3f8f5-4f56-4bc2-9537-022817f61f19)

产品中用“精力”作为便于理解的近似表述；心理学里的唤醒度不完全等于精力，紧张也可能伴随高唤醒和疲惫。两个维度只能帮助起步，不能涵盖混合感受，用户仍可以写出自己的复杂体验。

## 采用什么，不采用什么

| 研究观察 | 产品里的具体做法 | 不应声称 |
|---|---|---|
| 二维模型提供了一种描述感受的空间。 | 保留连续坐标；提供点选、拖动和可访问滑杆；本人决定并可修改。词语供选用或自写。 | 坐标能精确推断情绪，或 16 个标签是公认标准。 |
| 一项实验发现，在特定实验条件下，用词标注负性图片时与杏仁核反应降低相关。 | 可选地邀请用户写一句自己的感受，允许留空和“不知道”。 | 本产品已证实改善情绪、治疗或调节大脑。 [原研究](https://pubmed.ncbi.nlm.nih.gov/17576282/) |
| 日末回忆与多次当下记录有不同的记忆偏差和负担。 | 一天一条应明确是用户选定的“这一天的记录”，而不是自动声称全天平均；以后可探索自愿多时点。 | 单次记录代表当天每一刻。[比较研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7545330/) |
| 情绪表述更细致与部分结果存在关联，但不等于使用一张词表就带来因果改善。 | 在需要时提供少量自选词与自由输入，不强制选择。 | 词库越多越健康，或产品能提升心理健康。 [原研究](https://journals.sagepub.com/doi/10.1177/0956797610379863) |
| 一项包含 202 个研究的元分析发现，自主神经反应与情绪类别没有简单的一一对应。 | 设备信息只能作为有来源、用户可关掉的背景；缺乏有效数据就显示不足；绝不将脑电专注度映射为心情。 | 心率、睡眠或脑电能直接识别某种情绪。 [元分析](https://pubmed.ncbi.nlm.nih.gov/29389177/) |

## 被动建议与裁决

目标是用户授权后，以当日对话和真实可用的设备信息形成带出处的“可能是……吗？”候选，由用户修改、接受或忽略。候选不等于记录，不因为拒绝而持续追问；不能提取时宁可说“不确定”。候选引用应显示确切来源和时间范围，并允许撤销来源与删除结果。候选不自动触发健康诊断、危机等级或医疗结论。

当前项目里 MindLink 只有专注度读取，设备不在本机、尚未真机验收；Rokid 和 Apple Watch/Health 等缺少可用的真实心情数据连接。第一步仅允许用户自行提交的自述生成局部候选；**自动扫描对话、多设备融合、日终主动呈现和系统通知均未完成**。这不是对用户最终目标的替代，而是为了不在缺少数据和验证时虚构被动识别。

## 独立小实验

心情实验现已加入产品的「设置 → 实验区」；原[独立试验稿](心情实验室-20261030/index.html)作为过程记录保留。它不持久化输入、不连接模型或设备：A 连续地图；B 两条滑杆；两者共享数值，允许自由描述。对比目的是检查理解成本、表达自由、可访问性和被标签定义的不适感，不生成心理结论。

建议先邀请 5–8 名自愿参与者，以相同场景交替尝试两种方式，记录是否理解横纵轴、能否找到合适位置、是否觉得某个词被强加、完成时间、以及是否希望跳过。顺序交叉，允许“不知道”“复杂”“都不喜欢”。不要记录未经同意的私事，也不把一小组主观反馈当作验证疗效。**当前没有招募、受试者结果或效果数据。**

下一轮实验可比较“系统直接贴情绪标签”与“带可见依据的开放式询问”；应先用合成例子验证否定、引用、过去式、多重情绪和无证据等失败场景，检查误判和用户修正，不发送真实对话到外部模型。

我们还用 10 条合成语句做了首次规则检查：[查看输入和结果](心情实验室-20261030/合成语句检查.md)。它暴露出规则对自然语言覆盖非常有限；这是工程自检，不是真人体验或效果实验。
